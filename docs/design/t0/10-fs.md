# xdk.fs —— T0 文件系统 v1.1

| 项 | 值 |
| --- | --- |
| 包 | `xdk.fs` |
| 层级 | T0 |
| 稳定性 | `preview` |
| 依赖 | `xdk.bytes`、`xdk.errors`；OS 原语经 `sys_raw.xfb` |
| 被依赖 | config、cli、log |
| 对应源码 | `src/xdk/fs/FS.x`；同目录 `File.x`、`Dir.x`、`Path.x`、`Metadata.x`、`EntryKind.x`、`FileMode.x`、`TempFile.x`、`TempDir.x` |
| 当前状态 | Verified（Result 面、File/Dir/Path、Long offset、atomic/temp/walk/glob、metadata、权限/链接均通过） |

## 1. 能力

| 能力 | 说明 | 承载 | 层级 |
| --- | --- | --- | --- |
| CAP-1 存在性 | 文件/目录/符号链接判断 | `exists`、`isFile`、`isDir`、`isSymlink` | K |
| CAP-2 文本/字节读 | UTF-8 文本与二进制读取，失败走 `Result` | `readText`、`readBytes` | K |
| CAP-3 文本/字节写 | 覆盖写，返回 UTF-8/字节数 | `writeText`、`writeBytes` | K |
| CAP-4 文件句柄 | 打开/读写/seek/close/size；offset 与 size 用 `Long` | `File`、`openFile*` | X |
| CAP-5 目录 | 打开/逐项/列举/关闭 | `Dir`、`openDir` | X |
| CAP-6 路径 | 拼接/规范化/父子/扩展名/绝对判断 | `Path`、`pathJoin` | X |
| CAP-7 元数据 | 类型、字节数、mtime 毫秒、权限位 | `Metadata`、`metadata`、`linkMetadata` | X |
| CAP-8 权限 | 读取/设置 POSIX 权限位 | `permissions`、`setPermissions` | X |
| CAP-9 链接 | 符号链接创建/读取，硬链接创建，不跟随元数据 | `createSymlink`、`createHardLink`、`readLink`、`linkMetadata` | X |
| CAP-10 遍历 | 深度优先收集文件，glob 子集匹配 | `walk`、`glob`、`globMatch` | X |
| CAP-11 临时资源 | 唯一临时文件/目录，close 删除且幂等 | `TempFile`、`TempDir`、`createTempFile`、`createTempDir` | X |
| CAP-12 原子写 | 同目录临时文件 + `fsync` + `rename` 覆盖 | `writeTextAtomic`、`writeBytesAtomic` | X |
| CAP-13 文件操作 | 删除/重命名/复制/建目录/递归删除 | `removeFile`、`renameFile`、`copyFile`、`makeDir`、`removeDir`、`mkdirAll`、`removeDirAll` | X |

**非目标**：网络文件系统、文件锁、内存映射、ACL/xattr、递归 glob 之外的完整 POSIX
正则文件名集合。

## 2. 顶层函数（T0-K / T0-X）

```text
Bool exists(String path)
Bool isFile(String path)
Bool isDir(String path)
Bool isSymlink(String path)

Result<String, Error> readText(String path)
Result<Bytes, Error> readBytes(String path)
Result<Long, Error> writeText(String path, String text)
Result<Long, Error> writeBytes(String path, Bytes data)
```

| 函数 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `exists(path)` | path 非空 | 跟随符号链接后存在返回 true | 无（权限/缺失都返回 false） |
| `isFile(path)` / `isDir(path)` | path 非空 | 跟随链接后的类型判断 | 无 |
| `isSymlink(path)` | path 非空 | 不跟随链接的类型判断 | 无 |
| `readText(path)` | path 非空，目标非目录 | UTF-8 文本 | `NotFound`、`PermissionDenied`、`Io`、`InvalidArgument` |
| `readBytes(path)` | path 非空，目标非目录 | 二进制副本 | 同上 |
| `writeText(path, text)` | path 非空 | 覆盖写入，返回 UTF-8 字节数 | 同上 |
| `writeBytes(path, data)` | path 非空 | 覆盖写入，返回字节数 | 同上 |

- 文本必须 UTF-8；二进制使用 `Bytes`。
- 不提供隐式 flush；顶层写入完成即关闭。
- 禁止把“文件不存在”映射成空字符串或空字节串。

## 3. `File`（class）

```text
enum FileMode { Read, Write, Append, ReadWrite }

class File {
    File(String path)
    Result<Unit, Error> open(FileMode mode)
    Bool isOpen()
    Bool isReadable()
    Bool isWritable()
    Result<Long, Error> position()
    Result<Long, Error> size()
    Result<Unit, Error> seek(Long offset)
    Result<Bytes, Error> read(Long maximumBytes)
    Result<Bytes, Error> readAll()
    Result<String, Error> readText()
    Result<Long, Error> write(Bytes data)
    Result<Long, Error> writeText(String text)
    Result<Long, Error> writeLine(String line)
    Result<Unit, Error> flush()
    Result<Unit, Error> close()
}

Result<File, Error> openFile(String path, FileMode mode)
Result<File, Error> openFileRead(String path)
Result<File, Error> openFileWrite(String path)
Result<File, Error> openFileAppend(String path)
Result<File, Error> openFileReadWrite(String path)
```

| 方法 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `open(mode)` | 未打开，path 非空 | 取得 OS 句柄；`Write` 立即截断，`Append` 始终写到尾部 | `NotFound`、`PermissionDenied`、`Io`、`InvalidArgument` |
| `position()` | 已打开 | 当前字节偏移 | `Unavailable`、`Io` |
| `size()` | 已打开 | 文件当前字节数（`Long`） | `Unavailable`、`Io` |
| `seek(offset)` | 已打开，offset ≥ 0 | 后续读写从绝对 offset 开始 | `InvalidArgument`、`Unavailable`、`Io` |
| `read(maximumBytes)` | 已打开且可读，maximumBytes ≥ 0 | 读至多 maximumBytes 字节，返回副本 | `InvalidArgument`、`Unavailable`、`Io` |
| `readAll()` | 已打开且可读 | 从当前位置读到文件尾 | 同 `read` |
| `write(data)` | 已打开且可写 | 从当前位置写入，返回写入字节数 | `InvalidArgument`、`Unavailable`、`Io` |
| `flush()` | 已打开 | 刷新用户缓冲 | `Unavailable`、`Io` |
| `close()` | 无 | 关闭并释放句柄；幂等 | `Io`（仅报告诊断，句柄已释放） |

- offset 与 size 使用 `Long`；单次 read/write 上限 64 MiB，超过返回 `Unsupported`。
- `Append` 模式不可读；`Write` 模式不可读；`ReadWrite` 可读写。
- 关闭后读写返回 `Unavailable`；重复 `close()` 返回 `Ok()`。

## 4. `Dir`（class）

```text
class Dir {
    Bool isOpen()
    Result<String?, Error> next()
    Result<List<String>, Error> entries()
    Result<Unit, Error> close()
}
Result<Dir, Error> openDir(String path)
```

- `next()` 返回下一个条目名；目录结束返回 `Ok(null)`；`"."` 与 `".."` 被跳过。
- 遍历顺序不承诺；需要稳定顺序由调用方排序。
- `entries()` 消费剩余全部条目；关闭后调用返回 `Unavailable`。
- `close()` 幂等；关闭后持有的运行时目录槽位立即释放。

## 5. `Path`（class）

```text
class Path {
    Path(String raw)
    String toString()
    String text()
    Bool isAbsolute()
    String name()
    Path parent()
    String extension()
    Path join(String child)
    Path normalize()
}
String pathJoin(String basePath, String childName)
```

- 纯字符串操作，不访问文件系统；不解析 `~`、环境变量或盘符。
- 根 `/` 的 `name()` 为 `/`，`parent()` 为 `/`。
- `join` 遇到绝对 child 时返回 child；`normalize` 按词法折叠 `.`/`..` 和重复分隔符。
- `extension()` 不包含点；隐藏文件 `.bashrc` 的扩展名为空。

## 6. 元数据、权限与链接（T0-X）

```text
enum EntryKind { Missing, File, Directory, Symlink, Other }

class Metadata {
    final EntryKind kind
    final Long size
    final Long modifiedMillis
    final Int permissions
    Bool isFile()
    Bool isDirectory()
    Bool isSymlink()
    Bool isOther()
    Bool isExecutable()
}

Result<Metadata, Error> metadata(String path)
Result<Metadata, Error> linkMetadata(String path)
Result<Int, Error> permissions(String path)
Result<Unit, Error> setPermissions(String path, Int mode)
Result<Unit, Error> createSymlink(String target, String linkPath)
Result<Unit, Error> createHardLink(String target, String linkPath)
Result<String, Error> readLink(String path)
Result<String, Error> canonicalPath(String path)
```

- `metadata` 跟随符号链接；`linkMetadata` 使用 `lstat` 语义。
- `size` 为字节数，`modifiedMillis` 为 Unix 毫秒，`permissions` 为 `mode & 07777`。
- `setPermissions` 只设置低 12 位；`isExecutable` 检查任一执行位。
- `readLink` 只读取链接目标，不解析；`canonicalPath` 使用 `realpath` 语义。
- 链接目标为空是 `InvalidArgument`；已存在目标返回 `AlreadyExists`。

## 7. 遍历、glob、临时与原子写（T0-X）

```text
String pathJoin(String basePath, String childName)
Result<List<String>, Error> walk(String root)
Result<List<String>, Error> glob(String pattern)
Bool globMatch(String text, String pattern)

Result<TempFile, Error> createTempFile(String prefix)
Result<TempDir, Error> createTempDir(String prefix)
Result<Long, Error> writeTextAtomic(String path, String text)
Result<Long, Error> writeBytesAtomic(String path, Bytes data)
```

- `walk(root)`：深度优先返回 root 下的全部非目录条目；目录本身不返回；不跟随符号链接目录。
- `glob(pattern)`：支持 `*`（段内任意字符）、`?`（段内单字符）、`**`（跨段任意层）。
  不实现 `[...]`、`{...}`、转义；结果顺序不承诺；无匹配返回 `Ok([])`。
- `globMatch(text, pattern)` 暴露同一匹配器，便于调用方在已遍历结果上过滤。
- `createTempFile(prefix)` / `createTempDir(prefix)`：prefix 为空时使用系统临时目录；
  不含 `/` 时作为系统临时目录下的文件名前缀；含 `/` 时作为路径前缀。尾部自动补
  `XXXXXX`。返回值持有路径租约。
- `TempFile.close()` / `TempDir.close()`：删除租约（目录递归删除），幂等；删除后
  `isRemoved()` 为 true。
- 原子写：在目标同目录创建临时文件，写入后 `fsync`，保留既有权限（新文件按
  `0666 & ~umask`），最后 `rename` 覆盖目标；失败不留下临时文件。

## 8. 错误与所有权

- 错误分类固定映射：`NotFound`、`PermissionDenied`、`AlreadyExists`、`InvalidArgument`、
  `Io`、`Unsupported`、`Busy`；运行时错误码 0 表示成功。
- 所有可恢复失败返回 `Result`；只有调用方违反前置条件（例如负 offset、负权限位）
  返回 `InvalidArgument`，不使用 panic 表达文件系统失败。
- `File`/`Dir`/`TempFile`/`TempDir` 持有 OS 资源，必须 `close()`；全部 `close()` 幂等。
- `readBytes`/`File.read` 返回副本；写入借用调用方 `Bytes`。
- 关闭失败只报告诊断，不表示句柄未释放；后续 close 返回 `Ok()`。

## 9. 测试义务

- 顶层读写：ASCII、非 ASCII 字节数、空文件、缺失路径 `NotFound`；
- `File`：Long size/offset、seek 后读、seek 后写、append、flush、close 幂等、关闭后失败；
- `Dir`：entries 消费、next 到 `Ok(null)`、关闭后失败；
- `Path`：name/parent/extension/isAbsolute/join/normalize；
- metadata：文件/目录、size、permissions、linkMetadata 不跟随；
- 权限：setPermissions 后读回；
- 链接：符号链接读取/跟随/不跟随、硬链接内容、删除链接；
- 原子写：写入后内容一致；
- walk/glob：顶层与嵌套匹配、无匹配为空列表；
- temp：创建后存在、close 后删除、close 幂等；
- copy/rename/mkdirAll/removeDirAll；
- 端到端：`xdk_core.x` 同时覆盖 fs 新面与旧面。

场景：`xdk_fs.x`。

## 10. 缺口与非目标

- 无 T0-X 阻塞缺口。
- glob 只承诺 `*`/`?`/`**` 子集，不含字符类、花括号与转义。
- 不实现文件锁、mmap、ACL/xattr、递归符号链接跟随；这些不属于 T0。
- `src/xdk/io/system` 仍保留为 `xdk.sys` 完整面的过渡单元；`xdk.fs` 不依赖它。

## 11. T0-X 变更记录

- `readText` 从 `String` 改为 `Result<String, Error>`；`writeText` 从 `Int` 改为
  `Result<Long, Error>`，返回 UTF-8 字节数；新增 `readBytes`/`writeBytes`。
- 新增 `File`（`Long` offset/size、真实句柄 seek/read/write）与 `FileMode` 工厂。
- 新增 `Dir.next` 的 `Ok(null)` EOF 语义、`entries` 与幂等 `close`。
- 新增 `Path` 的 `normalize`/`join`/`parent` 返回值。
- 新增 `Metadata`/`EntryKind`、权限、符号/硬链接、`walk`/`glob`、temp 租约与原子写。
- 运行时新增 `sys_raw.xfb` 文件句柄、元数据、权限、链接、临时与原子写桥；
  `xdk.fs` 不再从 `xdk.sys` 借用文本面。
