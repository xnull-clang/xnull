# xdk.io —— T0 流与内存 I/O v1.0

| 项 | 值 |
| --- | --- |
| 包 | `xdk.io` |
| 层级 | T0 |
| 稳定性 | `preview` |
| 依赖 | `xdk.bytes`、`xdk.errors` |
| 被依赖 | fs、sys、log、config |
| 对应源码 | `src/xdk/io/IO.x`；完整文件/目录面在 `io/system` |
| 当前状态 | Verified（内存 Reader/Writer、严格读取、副本、组合流与 LineReader 通过） |

## 1. 能力

| 能力 | 说明 | 承载 |
| --- | --- | --- |
| CAP-1 顺序读 | 从内存字节序列读 U8/字节块 | `Reader` |
| CAP-2 顺序写 | 追加 U8/字节块 | `Writer` |
| CAP-3 严格读 | EOF 不返回哨兵；`Result` 或 panic | `Reader`、`Readable` |
| CAP-4 位置判断 | remaining/hasRemaining | `Readable` |
| CAP-5 快照 | 写出当前字节副本 | `Writer.toBytes` |
| CAP-6 缓冲 | 读/写缓冲与显式 flush | `BufferedReader`、`BufferedWriter` |
| CAP-7 组合 | 串联、旁路复制、长度封顶 | `ChainReader`、`TeeReader`、`LimitReader` |
| CAP-8 行读取 | LF/CRLF 行切分 | `LineReader` |
| CAP-9 整段 | 读尽、整段复制 | `readAll`、`copyTo` |

**非目标**：文件/网络/终端流、stdio、可取消 I/O、线程安全。

## 2. 协议（T0-X）

```text
protocol Readable {
    Int remaining()
    Bool hasRemaining()
    Int readU8()
    Result<Int, Error> tryReadU8()
    Bytes readBytes(Int count)
    Result<Bytes, Error> readExact(Int count)
    Bool isClosed()
    Result<Unit, Error> close()
}

protocol Writable {
    Int length()
    Void writeU8(Int value)
    Void writeBytes(Bytes source)
    Result<Unit, Error> flush()
    Result<Unit, Error> close()
    Bool isClosed()
}
```

- 组合类只依赖协议，因此可包装 `Reader`、`BufferedReader`、`ChainReader`、`TeeReader`、`LimitReader`。
- 失败通道固定：无 `Result` 的读取在 EOF/关闭/负数时是合同错误（panic）；`tryReadU8`/`readExact` 返回 `Result`，失败时位置不变。
- 所有 `close()` 幂等；重复关闭返回 `Ok()`。

## 3. `Reader`（class）

```text
class Reader implements Readable {
    Reader(Bytes source)
    Int remaining()
    Bool hasRemaining()
    Int readU8()
    Result<Int, Error> tryReadU8()
    Bytes readBytes(Int count)
    Result<Bytes, Error> readExact(Int count)
    Bool isClosed()
    Result<Unit, Error> close()
}
```

| 方法 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `remaining()` | 无 | 未关闭时为源长度 - 位置；关闭后为 0 | 无 |
| `hasRemaining()` | 无 | `remaining() > 0` | 无 |
| `readU8()` | 未关闭且未到 EOF | 返回当前字节并前进 1 | 关闭或 EOF 为合同错误（panic） |
| `tryReadU8()` | 无 | 成功前进 1；失败位置不变 | `DataCorrupted`（EOF）、`Unavailable`（已关闭） |
| `readBytes(count)` | 未关闭，`count >= 0` | 钳制到剩余长度，返回副本并前进 | 关闭或 `count < 0` 为合同错误（panic） |
| `readExact(count)` | 未关闭，`count >= 0` | 恰好读 `count` 字节；成功前进 `count` | 不足 `DataCorrupted`，位置不变；负数 panic |
| `close()` | 无 | 标记关闭；幂等 | 无 |

- 读取器借用源 `Bytes`；读取期间调用方不得修改源。
- 空读取器的 `readU8()` 不再返回 `0`；需要探测 EOF 必须用 `tryReadU8()` 或 `hasRemaining()`。

## 4. `Writer`（class）

```text
class Writer implements Writable {
    Writer()
    Int length()
    Bytes toBytes()
    Void writeU8(Int value)
    Void writeBytes(Bytes source)
    Result<Unit, Error> flush()
    Bool isClosed()
    Result<Unit, Error> close()
}
```

| 方法 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `writeU8(value)` | 未关闭 | 追加低 8 位 | 关闭后写入为合同错误（panic） |
| `writeBytes(source)` | 未关闭，source 非 null | 追加副本 | 关闭后写入为合同错误（panic） |
| `length()` | 无 | 当前字节数 | 无 |
| `toBytes()` | 无 | 当前内容**副本**；与写入器后续变化无关 | 无 |
| `flush()` | 无 | 内存写入器无事可做，返回 `Ok()` | 无 |
| `close()` | 无 | 标记关闭；幂等 | 无 |

- `writeBytes` 借用源并复制字节；`toBytes` 返回新所有权。
- 关闭后仍可调用 `length()`/`toBytes()` 读取快照，但不能继续写入。

## 5. 缓冲流（T0-X）

```text
class BufferedReader implements Readable {
    BufferedReader(Readable source, Int capacity)
}
class BufferedWriter implements Writable {
    BufferedWriter(Writable sink)
    Int bufferedLength()
    Bytes pendingBytes()
}
```

- `BufferedReader`：按 `capacity` 从源批量取数；不足时自动补块。`remaining()` 为“缓冲剩余 + 源剩余”。`capacity < 1` 为合同错误。
- `BufferedWriter`：写入先进入内部缓冲；`length()` 统计已接受字节总数，`bufferedLength()` 为尚未 flush 的字节数，`pendingBytes()` 返回待写缓冲副本。
- `BufferedWriter.flush()` 把缓冲写入 sink；sink 已关闭时返回 `Unavailable`，缓冲保留。
- `BufferedWriter.close()` 先 flush，成功后标记关闭并关闭 sink；flush 失败时不标记关闭、缓冲保留并返回该错误。重复 close 返回 `Ok()`。
- `BufferedReader.close()` 丢弃内部缓冲并关闭源。

## 6. 组合流（T0-X）

```text
class ChainReader implements Readable {
    ChainReader(Readable first, Readable second)
}
class TeeReader implements Readable {
    TeeReader(Readable source, Writable sink)
}
class LimitReader implements Readable {
    LimitReader(Readable source, Int maximumBytes)
}
```

- `ChainReader`：先读 `first`，耗尽后读 `second`；`remaining()` 为两个源之和。`readExact` 在总量不足时返回 `DataCorrupted` 且不消费任一源。
- `TeeReader`：每次读取原样写入 sink；`remaining()` 委托源。`close()` 只关闭源，sink 仍由调用方持有并可继续 flush/close。
- `LimitReader`：对外最多暴露 `maximumBytes` 字节；`remaining()` 取源剩余与限额剩余的较小值。达到限额后 `readU8`/`tryReadU8` 表现为 EOF，但不会越过源。
- 组合流失败时保持位置不变（`readExact`）或不前进（`tryReadU8`）。

## 7. 行读取与整段操作（T0-X）

```text
class LineReader {
    LineReader(Readable source)
    Result<String?, Error> readLine()
    Bool isClosed()
    Result<Unit, Error> close()
}
Result<Bytes, Error> readAll(Readable source)
Result<Int, Error> copyTo(Readable source, Writable sink)
```

| 方法 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `readLine()` | 未关闭 | 返回一行，不含行尾 LF；CRLF 去掉 CR；EOF 返回 `Ok(null)` | 底层非 EOF 错误原样返回 `Err`；已关闭 `Unavailable` |
| `readAll(source)` | source 未关闭 | 读尽剩余字节并返回副本 | 源已关闭 `Unavailable` |
| `copyTo(source, sink)` | 两者未关闭 | 读尽源并写入 sink，返回写入字节数 | 任一已关闭 `Unavailable` |

- 行读取只把 `DataCorrupted` 视为读取结束；其他错误必须向上返回，不能伪装成 EOF。
- 源末尾没有换行符时，最后一行仍作为一行返回；下一次 `readLine()` 返回 `Ok(null)`。

## 8. 错误与所有权

- 纯内存操作无 OS 资源；`close()` 只是状态与级联关闭，不产生系统调用。
- `readBytes` 返回副本；`tryReadU8`/`readExact` 失败不移动位置；`writeBytes` 借用源。
- `Writer.toBytes` 与 `BufferedWriter.pendingBytes` 返回副本，调用方修改返回值不影响流。
- EOF 语义统一为 checked/panic：`readU8` 到 EOF 是合同错误，`tryReadU8` 返回 `DataCorrupted`；禁止 `0` 哨兵。
- `close()` 幂等；关闭后再读取/写入的失败通道按方法声明：`tryReadU8`/`readExact` 返回 `Unavailable`，其余为 panic。

## 9. 测试义务

- 空/单字节/多字节读写；
- `readBytes` 钳制、负 count；
- `readU8` EOF panic 与 `tryReadU8` 失败不前进；
- `readExact` 成功/不足/负 count；
- `toBytes`/`pendingBytes` 副本独立性；
- `flush`/`close` 幂等与关闭后写入失败；
- `BufferedReader` 小块跨读、`BufferedWriter` flush/close 级联；
- `ChainReader` 跨源、`TeeReader` 旁路、`LimitReader` 封顶；
- `LineReader` LF/CRLF/末尾无换行/EOF；
- `readAll`/`copyTo`；
- base/full 输出一致。

场景：`xdk_io.x`；端到端：`xdk_core.x`。

## 10. 缺口与非目标

- 无 T0-X 阻塞缺口。
- 文件、网络、终端流与 stdio 不在本包：文件面由 `xdk.fs`/`xdk.sys` 接入，stdio 由 `xdk.runtime`/`xdk.sys` 接入。
- 不承诺线程安全与可取消 I/O；需要跨任务共享时由调用方加锁。

## 11. T0-X 变更记录

- `Reader.readU8` 的 EOF 由 `0` 哨兵改为 panic；新增 `tryReadU8`、`readExact`。
- `Writer.toBytes` 由别名改为副本；新增 `flush`/`close`/`isClosed`，关闭后写入为合同错误。
- 新增 `Readable`/`Writable` 协议、`BufferedReader`/`BufferedWriter`、`ChainReader`/`TeeReader`/`LimitReader`、`LineReader`、`readAll`/`copyTo`。
- 为让协议分发支持 `Result` 返回，mini 协议兜底返回零值按返回类型生成（`xn_Result` 等结构体不再用 `return 0`）。
