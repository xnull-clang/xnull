# xdk.io —— T0 流与内存 I/O v1.0

| 项 | 值 |
| --- | --- |
| 包 | `xdk.io` |
| 层级 | T0 |
| 稳定性 | `preview` |
| 依赖 | `xdk.bytes`、`xdk.errors` |
| 被依赖 | fs、sys、log、config |
| 对应源码 | `src/xdk/io/IO.x`；完整文件/目录面在 `io/system` |
| 当前状态 | Partial（内存 Reader/Writer 通过；严格读取/副本语义待补） |

## 1. 能力

| 能力 | 说明 | 承载 |
| --- | --- | --- |
| CAP-1 顺序读 | 从内存字节序列读 U8/字节块 | `Reader` |
| CAP-2 顺序写 | 追加 U8/字节块 | `Writer` |
| CAP-3 位置判断 | remaining/hasRemaining | `Reader` |
| CAP-4 快照 | 写出当前字节 | `Writer.toBytes` |

**非目标**：文件/网络/终端流、Buffered、Chain/Tee/Limit、LineReader、
Reader/Writer 协议抽象、可取消 I/O。

## 2. `Reader`（class，T0-K）

```text
class Reader {
    Reader(Bytes source)
    Int remaining()
    Bool hasRemaining()
    Int readU8()
    Bytes readBytes(Int count)
}
```

| 方法 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `remaining()` | 无 | 源长度 - 位置 | 无 |
| `hasRemaining()` | 无 | 是否还有字节 | 无 |
| `readU8()` | 无 | 有字节则返回并前进 1 | 当前实现 EOF 返回 0；这是已登记缺口，T0-X 改 panic/checked |
| `readBytes(count)` | `count >= 0` | 钳制到剩余长度，返回副本 | 负数为合同错误 |

- 读取器借用源 `Bytes`；读取期间调用方不得修改源。
- 无 `close()`；非线程安全。

## 3. `Writer`（class，T0-K）

```text
class Writer {
    Writer()
    Int length()
    Bytes toBytes()
    Void writeU8(Int value)
    Void writeBytes(Bytes source)
}
```

| 方法 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `writeU8(value)` | 无 | 追加低 8 位 | 无 |
| `writeBytes(source)` | source 非 null | 追加副本 | 无 |
| `toBytes()` | 无 | 当前内容；**契约要求副本** | 当前实现返回别名，已登记缺口 |

- T0-X 增加 `flush/close`、Buffered、Chain/Tee/Limit、LineReader。
- 文件/网络流通过 T0-X/T1 的 `File`/Stream 接入，不在此包承诺。

## 4. 错误与所有权

- 纯内存操作无 OS 资源，无 `close()`。
- `readBytes` 返回副本；`writeBytes` 借用源。
- EOF 语义必须在 T0-X 统一为 checked/panic，禁止长期保留 0 哨兵。

## 5. 测试义务

- 空/单字节/多字节读写；
- `readBytes` 钳制、负 count；
- `toBytes` 副本独立性（缺口修复后）；
- base/full 输出一致。

场景：`xdk_io.x`。

## 6. 已知缺口

- `readU8` EOF 返回 0；
- `Writer.toBytes` 返回别名，不是副本；
- 缺少 `tryReadU8`/`readExact`；
- 文件/网络/终端流未实现。
