## 1. 能力

| 能力 | 说明 | 承载 | 层级 |
| --- | --- | --- | --- |
| CAP-1 存在性 | 文件/目录存在判断 | `exists` | K |
| CAP-2 文本读 | 读取 UTF-8 文本 | `readText` | K |
| CAP-3 文本写 | 写入/覆盖文本 | `writeText` | K |
| CAP-4 文件句柄 | 打开/读写/关闭/seek | `File` | X |
| CAP-5 目录 | 打开/遍历/关闭 | `Dir` | X |
| CAP-6 路径 | 拼接/规范化/父子 | `Path` | X |

**非目标**：网络文件系统、权限模型、符号链接语义、原子写、临时文件、
glob/walk、内存映射。

## 2. 顶层函数

```text
Bool exists(String path)
String readText(String path)
Int writeText(String path, String text)
```

| 函数 | 前置 | 后置 | 失败 |
| --- | --- | --- | --- |
| `exists(path)` | path 非空 | 存在返回 true，否则 false | 无（不可区分权限/缺失） |
| `readText(path)` | path 非空 | UTF-8 文本 | 当前实现失败会诊断/抛出；X 改 `Result` |
| `writeText(path, text)` | path 非空 | 覆盖写入，返回字节数 | 当前返回 `Int`；X 改 `Result<Long,Error>` |

- 路径分隔符按平台； 只保证 `/` 和平台原生分隔符。
- 文本必须 UTF-8；二进制使用 `Bytes` + File X。
- 不提供隐式 flush；`writeText` 完成即关闭。

## 3. X `File`/`Dir`/`Path`

- `File`：`open/read/write/seek/close/size`，`size` 用 `Long`。
- `Dir`：`open/next/close`，遍历顺序不承诺。
- `Path`：`join/name/parent/extension/isAbsolute`。
- 所有 OS 资源必须显式 `close()`；失败通过 `Result` 返回。

## 4. 错误

- `NotFound`、`PermissionDenied`、`Io`、`InvalidArgument`。
-  顶层函数当前是简化面；X 的 File/Dir 必须是 `Result` 面。
- 不允许把“文件不存在”映射成空字符串。

## 5. 测试义务

- 存在/不存在；
- 写入后读取一致；
- 空文本/非 ASCII；
- 文件句柄 close 幂等（X）；
- 目录遍历（X）。

场景：`xdk_fs.x`。

## 6. 已知缺口

- 顶层 `readText/writeText` 还不是 `Result` 面；
- File/Dir/Path 只有源码实现，未纳入 K 场景；
- 大文件 offset 仍用 `Int`，X 改 `Long`；
- 原子写、临时文件、walk/glob 未实现。
