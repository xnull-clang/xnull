# `Int128`

| 项 | 值 |
| --- | --- |
| 类型 | 语言标量（不是 class） |
| 包 | `xdk.math` |
| 稳定性 | `stable` |
| 依赖 | 无 |

---

## 1. 定位

有符号 128 位整数标量；用于宽字面量、大整数中间值、checked 算术。

不做：任意精度、Decimal、BigInt、位集。

---

## 2. 设计逻辑

- 语言内建标量，不在 XDK 声明 class。
- 二进制补码，范围 `-2^127 .. 2^127-1`。
- 支持宽字面量、四则/比较、`print`/`str`、函数参数/返回值、`Result<Int128,Error>`。
- 溢出按 checked 函数处理；普通 `+ - *` 按语言规则回绕/panic 由语言定义。
- 与 `Long` 显式转换；不隐式提升。

---

## 3. 表示与不变量

| 项 | 说明 |
| --- | --- |
| 宽度 | 128 位 |
| 符号 | 有符号 |
| 表示 | 二进制补码 |
| 范围 | `-170141183460469231731687303715884105728` 到 `170141183460469231731687303715884105727` |

不变量：值始终在范围内；字面量越界是编译期错误。

---

## 4. 生命周期

值类型；无 close；可共享。

---

## 5. 构造契约

- 宽字面量；
- 从 `Int`/`Long` 显式转换；
- `Result<Int128,Error>` 作为 checked 函数返回值。

---

## 6. 字段表

无字段；语言标量。

---

## 7. 方法面

`Int128` 没有 XDK 方法；运算由语言运算符和 `xdk.math` 顶层 checked 函数提供：

| 组 | 能力 |
| --- | --- |
| 字面量 | 宽十进制字面量 |
| 运算 | `+ - * / %`、比较 |
| 文本 | `print`/`str` |
| 函数 | 参数/返回值、`Result<Int128,Error>` |
| checked | `addI128Checked`、`subI128Checked`、`mulI128Checked`、`divI128Checked`、`modI128Checked`、`negI128Checked`、`absI128Checked` |
| 边界 | `int128Min`、`int128Max` |

---

## 8. 使用的技术

- 128 位整数；
- 二进制补码；
- 宽字面量解析；
- checked 溢出检测；
- 十进制打印。

---

## 9. 需要的支撑

- 语言：`Int128` 标量、字面量、运算符、`Result`；
- 运行时：128 位算术/打印；
- 接口：`BasicError`、`ErrorKind`。

---

## 10. 依赖的特性/接口/类

`BasicError`、`ErrorKind`、`Result`。

---

## 11. 所有权与并发

值语义；可共享；无资源。

---

## 12. 示例与反例

正确：`Int128 value = 170141183460469231731687303715884105727`；`addI128Checked(value, 1)` 返回 Err。  
反例：把 Int128 当任意精度；隐式塞进 Long；忽略 checked 结果。

---

## 13. 测试/场景义务

边界字面量；四则/比较；`print/str`；checked 溢出/除零/`MIN`；`Result<Int128,Error>` 往返。

---

## 14. XNull 伪代码

```xnull
Int128 minimum = -170141183460469231731687303715884105728
Int128 maximum = 170141183460469231731687303715884105727
Int128 value = 170141183460469231731687303715884105727

Result<Int128, Error> addI128Checked(Int128 left, Int128 right) {
    if right > 0 && left > maximum - right {
        return Err(new BasicError(ErrorKind.InvalidArgument, "int128 overflow"))
    }
    if right < 0 && left < minimum - right {
        return Err(new BasicError(ErrorKind.InvalidArgument, "int128 underflow"))
    }
    return Ok(left + right)
}

Result<Int128, Error> divI128Checked(Int128 left, Int128 right) {
    if right == 0 {
        return Err(new BasicError(ErrorKind.InvalidArgument, "division by zero"))
    }
    if left == minimum && right == -1 {
        return Err(new BasicError(ErrorKind.InvalidArgument, "int128 overflow"))
    }
    return Ok(left / right)
}
```
