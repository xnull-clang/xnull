# M6-B0-01 / P-09 执行命令

工作区 `wt/e4-codegen`（分支 `pod/e4-codegen`）；除注明外均在 `impl/` 下执行。

## 先红

```
go test ./internal/codegen -run 'TestFFI' -count=1 -v
```

原始输出 `before/ffi-before.log`：`undefined: LoadFFI / InjectFFI / EmitCWithFFI`，exit 1。

## 后绿

```
go test ./internal/codegen -run 'TestFFI' -count=1 -v
go test ./internal/codegen -run 'TestFFI|TestMultiFile|TestLoadUnits|TestCompile|TestXdkSeed|TestExitCode|TestTopField' -count=1 -v

go test ./internal/codegen/ffi/... -count=1
go test ./internal/interp/... ./internal/cli/... -count=1

```

原始输出：`after-codegen-tests.log`、`after-examples.log`、`after-ffi.log`、`after-interp-cli.log`（均 exit 0；gofmt/vet 无输出）。

说明：`TestExamplesCompileMatchesInterp/parser-seed.x` 为已知 P0-1（E3 负责），未在本卡执行。

## 样例（sample/）

```
# 1) 走 xnull build：C 生成与编译通过，链接差原生符号/清单（P-10 归 E6）
go run ./cmd/xnull build ../evidence/M6-B0-01/sample/main.x -o ../evidence/M6-B0-01/sample/prog

# 2) 按 P-09 验收面手工链接原生符号后运行
cc -std=c11 -O2 -Wno-unused-function -I runtime \
   -o ../evidence/M6-B0-01/sample/prog-ffi \
   ../evidence/M6-B0-01/sample/prog.c ../evidence/M6-B0-01/sample/native.c \
   runtime/rt.c runtime/rt_gc.c runtime/rt_policy.c runtime/rt_weak.c runtime/xrt_abi.c
../evidence/M6-B0-01/sample/prog-ffi

# 3) 解释路径 oracle（等价纯 XNull 程序）
go run ./cmd/xnull run ../evidence/M6-B0-01/sample/oracle.x --interp
diff -u sample/interp-stdout.txt sample/compiled-stdout.txt
```
