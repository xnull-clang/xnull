## 字段类型为空根因（不是 GC）
`emitStr()` 只处理 StrLit/Binary/Index/Call 等，遇到 `Paren`/`Ternary` 落到末尾返回
`rt_string_from_c("")`。类字段类型发射是：
```c
ce.add("    " + (fty0 == "Bool" ? "int64_t" : cType(fty0)) + " " + name + ";")
```
String 拼接走 `emitStr`，`Paren(Ternary)` 被发成空串 → ` sc; raw; nm;`。
解释器执行源码时自己求值 ternary，所以只有 self C 错。
修复：`emitStr` 增加 `Paren` 透传与 `Ternary`（cond 求值 + then/else 两个 `emitStr`
分支 + 结果 temp + rootStr）。已用 `"x" + (b ? "y" : "z")` 小样例验证生成
`if ((b)) { t = "y"; } else { t = "z"; }`。

## 其他修复（本提交一并）
- `List<N> x = call()` / `List<T>` / `Set` / `Map` 局部初始化：非字面量 init 现在走
  `expr(init)`，不再被 isObjArr/isTupList 分支当成空数组发成 `_new(0)`
  （此前导致 native 下 `sortedClassDecls` 恒空、类前向声明缺失）。
- 3 处 `while b > 0 && strLess(x, xs.get(b-1))` 改为嵌套 while/if，避免 Call 实参
  get 提前求值造成 prelude OOB。
- `--fast-roots`：哈希 root 表 + 单 GC root box，绕过运行时 `g_roots` 线性扫描。
- escape/unq 哈希集合。
