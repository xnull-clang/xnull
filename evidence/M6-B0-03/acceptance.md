## 实现

- `multifile.go`：删除 `RES-109` 同包限制与常量；导入边记录后在命名包 → 默认包文件时报 `RES-110`（§3.3）；保留依赖优先后序、环检测与确定性。
- 符号模型（起步形态）：多包声明在同一翻译单元内扁平链接；跨包同名顶层声明由 sema/codegen 显式报错。

## 未测项 / 边界（起步形态）

1. **包前缀符号**（§3.4「类型和顶层函数在内部带包前缀」）未实现：不同包的同名类型/函数不能共存（显式报错，不静默）。
2. 导入可见性未按包限定：扁平合并后，未 import 的包符号在名称解析层可见（源码侧仍应按 §3.3 使用 import）。
3. `import ... as` / 符号导入的跨包解析沿用 sema 既有能力（PKG-01 主线），本卡只闭环加载与链接。
4. 包名末段重名（不同路径同末段）不参与命名空间（§3.3 明确不绑定）。
5. 工程清单入口包解析（§11.4）仍属工程配置批次。
