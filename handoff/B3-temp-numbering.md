# B3 temp 编号规范（Go codegen 现行行为）

> 目的：给 E2 的 C 文本 diff 对齐用。只描述**现行 Go 实现**（`main@d02b3d2` 基线，
> B3-00 冻结 oracle），不是新规范；B3 的 XNull 版 `xnullc` 必须复现同一分配顺序。
> 代码位置：`impl/internal/codegen/codegen.go`（`gen.nextTmp`、`scope.tmp`、两遍发射）。

## 1. 计数器与两遍发射

- 唯一计数器：`gen.tmp int`；`nextTmp()` 先 `++` 再命名：
  ```go
  func (g *gen) nextTmp() string { g.tmp++; return fmt.Sprintf("xn_t%d", g.tmp) }
  ```
- **N 从 1 开始，翻译单元内单调递增**；不按函数重置。
- 发射分两遍：
  1. 第一遍“试生成”收集 Result/容器/泛型实例（产物丢弃）；
  2. `g.tmp = 0` 后第二遍正式生成（`codegen.go:642`）。
- 最终文本只含第二遍编号；第一遍分配的号**不会**影响最终 N。
- `taskID` 是独立计数器（`xn_task_<n>`），不占用 `xn_tN`。
- 根帧标记 `size_t xn_tN = xn_root_mark();` **也是**通过 `s.tmp()` 分配，计入同一序列。

## 2. 作用域与根帧占号

- 函数/方法/构造器作用域创建时先分配**函数根帧号**：
  `sc.rootMark = g.nextTmp()`（`codegen.go:1896` 附近）。
- 每个子块（if/else/while/for/switch case/try/块语句）由 `newChild()` 创建时
  **立即**分配一个根帧号（`rootMark: s.tmp()`），即使该块为空也占号；
  该号在块的 `size_t xn_tN = xn_root_mark();` 处出现。
- 因此“控制流块”会额外消耗 N，顺序取决于块的**创建时机**（见 §4）。
- 函数参数根登记（`xn_root_add(xn_p_x)`）不占新号。

## 3. 表达式内的求值/占号顺序（后缀式）

表达式按**深度优先、左到右**；操作数临时先于结果临时。要点：

1. **二元 `+`（字符串）**：先 `strExpr(L)` 的全部临时，再 `strExpr(R)`，最后
   分配拼接结果 `xn_tN = xn_concat(...)`（`codegen.go:4144`）。
2. **字面量/标识符**：字符串字面量分配一个 `rt_string_from_c` 临时；
   标识符 `strExpr` 分配一个 `rt_string *xn_tN = rt_retain(name);`。
3. **成员读取**：先求接收者（若是调用则先占接收者临时），再取字段；
   String 字段读取会再分配一个 `rt_retain(recv->field)` 临时。
4. **方法调用**：
   - 先求接收者（`self.x` 不占；`self.m()`/`f()` 若返回类/String 会先占临时）；
   - 再按源码顺序求实参（左→右），每个实参自己的临时先分配；
   - 最后按返回类型决定是否占结果临时（String/类/容器/Result 等）。
5. **普通函数调用**：`callArgs` 左→右求实参；结果临时在调用后分配。
6. **FFI 调用**（`ffiCallLines`/`ffiResultLines`）：
   - 按 `.xfb` 形参声明顺序编组，临时按参数顺序生成；
   - 返回槽临时先于 `int32_t rc`；
   - Result 构造：out（如有）→ rc → Result 结构临时。
7. **同语句节点缓存**：同一语句内对**同一个 AST Call 节点**重复读取（如
   `self.cur().kind` 两次调用同一节点）复用已生成的接收者临时/表达式，
   **不再占新号**（`recvTemps`/`callExpr` 缓存，每语句清空）。
8. `rootTempDecls` 只追加 `xn_root_add(name)` 行，不分配新号。

## 4. 语句/控制流的占号顺序

- **局部声明**：先求初始化表达式临时；String 声明会把最后一个临时“改名”为目标
  变量（不新增号）；类/容器临时按 §3。
- **赋值**：先求右值临时；目标变量本身不占号。
- **return**：先求返回值表达式（全部临时）；标量/Float 返回再分配一个
  “返回槽”临时；Result 返回使用固定 `xn_ret`（无新号）；类 `new` 返回先分配
  对象临时。清理（defer/root_restore）不再占号。
- **if**：条件临时（含字符串比较/方法调用）→ then 块根帧 → then 体 →
  else 块根帧 → else 体。
- **while**：
  - 条件无前置语句：条件临时 → 循环体根帧 → 体（体前是条件求值）；
  - 条件产生前置语句（降级 `while(1)`）：条件临时 → 循环体根帧 → 体。
- **for-in**：**先创建循环体作用域并发射体**（体临时号在前）→ 再分配循环下标
  `size_t xn_tN`（`emitForIn` 中 `idx := s.tmp()` 在 body 之后）。
- **switch**：先求值被匹配表达式/各 case 条件临时 → 依次每个 case 根帧/体 →
  default 根帧/体。
- **defer 块**：语句体在注册点顺序发射（占号发生在 `defer` 语句处）。
- **try**：`Result` 临时与解包临时在声明/表达式处顺序生成（`emitTryInto`）。

## 5. 翻译单元级顺序（影响跨函数编号）

第二遍按以下顺序生成函数体，`g.tmp` 不重置：

1. 顶层普通函数：按 `LoadUnits` 合并后的 `u.Decls` 顺序（依赖后序，入口通常最后）；
2. 泛型函数实例：按实例名排序（`instNames()`）；
3. 类/结构体/单例/工厂/扩展：按其声明顺序；类方法按 `d.Methods` 声明顺序；
4. 延迟生成的任务闭包体（`lateFns`）在收尾阶段追加，编号位于同遍最后；
5. 顶层字段初始化、enum 初始化等若有临时，按其生成阶段插入（不重新编号）。

因此“函数 A 的 N 范围”取决于此前所有声明的生成长度；**不能按单个函数独立从 1 编号**。

## 6. 给 E2 的对齐清单

1. 先固定“第二遍 = 1 起”；第一遍不得泄漏编号。
2. 每个作用域创建即占根帧号（含空块），顺序按 §4。
3. 表达式严格后缀式左→右；收/实参先于结果；String 拼接结果最后占号。
4. for-in 的体先于下标；if/while 条件先于块根帧。
5. return 的返回槽临时在表达式之后、清理之前。
6. 同语句同一 AST 调用节点只求值一次/只占一次号。
7. 跨函数不重置计数器；函数顺序按 §5（`u.Decls` 依赖后序、实例名排序、声明序）。
8. 建议 E2 先用“空 main / hello / 单字符串拼接 / if+String / for-in”五个最小样例
   对拍 `xn_tN` 序列，再上 909 行文本。
