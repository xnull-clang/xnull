# XNull

**اكتب الشيفرة. بلا طقوس.**

لا lifetimes. لا تعليقات ملكية. لا `@Override`. لا `try/catch`. لا getters/setters. لا انعكاس.

XNull لغة برمجة جديدة يختار فيها المترجم لكل كائن المكدس أو ARC أو GC وفق جدول قرارات مكتوب في المواصفة. أنت تكتب البيانات والسلوك؛ وينفّذ وقت التشغيل الاختيار. إدارة ذاكرة بلا تعليقات ملكية — وبلا سحر خفي من المترجم.

الأخطاء قيم. تعدد الأشكال بروتوكولات. الحقول حقول. تسجّل المواصفة كل قرار، بما في ذلك كل ميزة مرفوضة وسببها.

```x
class Counter {
    Int n = 0

    Int add(Int v) {
        self.n = self.n + v
        return self.n
    }
}

static Int main() {
    Counter c = new Counter()
    print(c.add(2))
    return 0
}
```

| لم تعد تكتب | XNull يمنحك |
| --- | --- |
| `Arc<Mutex<T>>` وlifetimes | المترجم يختار الذاكرة (المكدس / ARC / GC) |
| `getX()` / `setX()` | حقول مباشرة |
| `extends` + `@Override` | بروتوكولات |
| `try/catch` | `Result<T,E>` + `try` |
| الانعكاس | غير قابل للتعبير |

## لماذا XNull

- **إدارة الذاكرة يقررها المترجم.** لا يعبّر النص المصدري عن قوة المراجع. يختار المترجم لكل كائن المكدس أو عدّ المراجع (ARC) أو جمع القمامة (GC) وفق جدول القرارات DET-01؛ وينفّذ وقت التشغيل هذا القرار.
- **لا نمط وصول.** الحقول بيانات؛ والسلوك دوالّ بأسماء فعلية. لا يمكن التعبير عن getters/setters.
- **التركيب قبل الوراثة.** لا تدعم الأصناف الوراثة القائمة على التجاوز. لا يتحقق تعدد الأشكال إلا عبر البروتوكولات.
- **الأخطاء هي قيم.** `Result<T,E>` و`try` و`defer`/`errdefer`. لا استثناءات، ولا فكّ ضمني للمكدس.
- **لا انعكاس.** ما لا يحدده النص المصدري والمواصفة ليس جزءًا من اللغة.
- **كل قرار موثّق.** تسجّل المواصفة ما تدعمه XNull وما ترفضه ولماذا. الأصول بالصينية مع ترجمات إنجليزية؛ نرحّب بمزيد من الترجمات.

## بنية المستودع

```text
assets/               الشعار وموارد المشروع
docs/                 وثائق البنية واللغة والتصميم
README/               ملفات README المترجمة
ide/                  إضافة VS Code وبيئة الويب
src/                  شجرة التطوير
  cli/xnull           واجهة CLI موحدة
  mini/               المترجم الأدنى ذاتي الاستضافة
  runtime/            مصادر وترويسات وقت التشغيل C
  xdk/                مصادر XDK
  ffi/                جسور FFI الخام ‏(.xfb)
  toolchain/          سكربتات البناء والتغليف
  examples/           أمثلة قابلة للتشغيل

xdk/                  حزمة تسليم XDK
  lib/xdk/            مصادر حزم XDK
  runtime/            مصادر وترويسات وقت التشغيل C
  ffi/                جسور FFI الخام
  install.sh          مثبّت POSIX sh
```

`src/` هو نقطة التعديل؛ `xdk/` هو نسخة التسليم. بعد تعديل `src/xdk/` يجب مزامنتها مع `xdk/lib/xdk/`.

## التطوير

`src/` شجرة التطوير، و`xdk/` نسخة التسليم. بعد تعديل `src/xdk/` يجب مزامنته مع `xdk/lib/xdk/`.


### تثبيت XDK

```sh
cd xdk
./install.sh --prefix "$HOME/.local"
```

يتم التثبيت في:

```text
<prefix>/share/xnull/xdk
<prefix>/share/xnull/runtime
<prefix>/share/xnull/ffi
```

للتغليف استخدم `DESTDIR`:

```sh
DESTDIR=/tmp/xdk-pkg ./install.sh --prefix /usr/local
```

## الحالة الحالية

| المجال | الحالة |
| --- | --- |
| المواصفات S1–S5 وS7–S8 | معتمدة |
| فهرس XDK S6 | v3.0.0 مسودة؛ نواة T0 أولاً |
| أدوات C الأصلية | تعمل للسيناريوهات الأساسية الحالية |
| المترجم الأدنى | اللغة الأساسية + أصناف أساسية؛ التغطية تتوسع |
| سيناريوهات من طرف إلى طرف | hello والأصناف و`import xdk.errors` ناجحة؛ المزيد قيد العمل |
| الاستضافة الذاتية | مخطط لها |

## غير مدعوم صراحةً (بحسب التصميم)

| الميزة | السبب |
| --- | --- |
| تجاوز الدوال | يجب أن يكون السؤال «أي دالة نُفّذت فعلاً؟» قابلًا للإجابة من الأنواع الساكنة؛ الإرسال الديناميكي موجود فقط عبر البروتوكولات |
| أنماط الوصول / الخصائص | فصل على مستوى القواعد: الحقول بيانات، والسلوك دوالّ بأسماء فعلية |
| الانعكاس | ينقض مسلّمة «النص المصدري + المواصفة يحددان كل شيء» |
| الاستثناءات | الأخطاء قيم: `Result` + `try`؛ `throw` قاتل فقط ولا يفكّ المكدس |

## خارطة الطريق

1. الواجهة الخلفية C الأصلية: ملف واحد يُترجم إلى C، ثم C إلى ملف ثنائي، ثم يعطي الملف الثنائي النتيجة.
2. إكمال تدريجي: تقوده سيناريوهات قابلة للتشغيل، لا قوائم ميزات.
3. الاستضافة الذاتية: إعادة كتابة المترجم بلغة XNull.

## تمويل الملاك

تبحث XNull عن جولة تمويل ملاك صغيرة أو دعم لا يخفّض حصص الملكية لتمويل 12–18 شهرًا من العمل على المترجم والاستضافة الذاتية ووقت التشغيل وXDK. الهدف ضيق: جعل الأدوات الحالية صحيحة وسريعة وقابلة للاستخدام أولاً، ثم توسيع اللغة.

إذا كنت مهتمًا، راسلنا على **vjsplus@163.com** بعنوان `XNull Angel`. تُناقش الشروط بشكل خاص.
