## 0. 定位

诊断层是工具链唯一的错误呈现面：

- 组件只产生结构化 `Diagnostic`；
- 诊断层负责格式、源码行、插入符、提示；
- CLI 决定写 stderr 与退出码；
- 诊断内容必须可定位、可复现、可被 CI 稳定解析。

```
xfront/sema/codegen/ffi/xpd/cli
        │ Diagnostic 值
        ▼
     diag 渲染
        │ 文本
        ▼
      stderr
```

---

## 1. 诊断结构

```go
type Diagnostic struct {
    File    string
    Line    int
    Col     int
    Code    string
    Message string
    Snippet string
    Width   int
    Hint    string
}
```

| 字段 | 说明 |
| --- | --- |
| `File` | 源文件/清单/伪文件名（如 `xnull`） |
| `Line`/`Col` | 1 基位置 |
| `Code` | 稳定诊断码（如 `TY-101`） |
| `Message` | 单行错误描述 |
| `Snippet` | 出错行原文；可空 |
| `Width` | 插入符覆盖宽度；0 视为 1 |
| `Hint` | 追加说明/修复建议 |

约束：

- `Message` 不换行；
- `Hint` 可包含可用字段/修复建议；
- `Snippet` 不含行号；
- 位置按 Unicode 标量计数；
- 诊断是错误，不设 warning/info 级别（当前设计）。

---

## 2. 渲染格式

### 2.1 无源码行

```
file:line:col: error[CODE]: message
  hint
```

### 2.2 有源码行

```
file:line:col: error[CODE]: message
 12 |   source line
    |     ^^^ hint
```

规则：

- 行号右对齐， gutter 与行号等宽；
- 插入符从 `Col` 开始；
- `Width` 控制 `^` 数量；
- `Hint` 跟在插入符后；
- 空 `Snippet` 只输出 message + hint；
- 列号越界时按 0 处理，至少 1 个 `^`；
- 不输出 ANSI 颜色（CI 稳定优先）。

### 2.3 示例

```
xnull.project:12:3: error[XPD-204]: unknown field "optonal" in dependency
  12 |   optonal = true
     |   ^^^^^^^ 未知字段；可用字段：version, scope, optional, exclusions
```

## 3. 诊断码段位

| 段位 | 归属 | 典型码 |
| --- | --- | --- |
| `LEX-1xx` | 词法 | LEX-101—106 |
| `SYN-1xx` | 语法 | SYN-101—111 |
| `RES-1xx` | 名称/导入/多文件 | RES-101—110 |
| `DA-1xx` | 确定赋值 | DA-101—103 |
| `TY-1xx` | 类型检查 | TY-101/103/104/105 |
| `TY-2xx` | 类型声明 | TY-201—207 |
| `ERR-2xx` | Result/清理规则 | ERR-201—206 |
| `FFI-1xx` | 绑定合同 | FFI-100—111 |
| `XPD-0xx—8xx` | 工程配置 | 词法/文法/段落/依赖/插件/配置/元数据/资源 |
| `CLI-0xx` | 命令行 | CLI-001—003、CLI-901 |

规则：

- 码值稳定；
- 新增码落在既有段位；
- 跨段位新增视为设计变更；
- 诊断码与文案模板固定；
- 不把内部异常/panic 文本直接当诊断码。

---

## 4. 位置与源码片段

### 4.1 位置

- 行/列 1 基；
- 列按 Unicode 标量计数；
- BOM 不计列；
- CRLF 归一化后计列；
- 插值表达式诊断使用宿主文件位置，Hint 标注“插值表达式”。

### 4.2 源码片段

- `Snippet` 为出错行原文，不含行号；
- 超长行可截断，但插入符位置需对应截断后文本；
- 多行 span 暂不支持（单行插入符）；
- 源文件不可读时允许无 `Snippet`。

### 4.3 段落路径

工程配置诊断需包含段落路径，例如：

```
project/dependencies/dependency[2]/optional
```

路径用于定位重复/未知字段/冲突。

---

## 5. 排序与确定性

诊断排序键：

1. `File`
2. `Line`
3. `Col`
4. `Code`

规则：

- 同一输入同一顺序；
- 不用 map 遍历顺序；
- FFI 解析按文件路径字典序；
- 工程配置按文件/行/列；
- 多文件编译按装载顺序产生，渲染前稳定排序；
- 同一位置多诊断按码排序。

---

## 6. 组件产生诊断的规则

| 组件 | 产生方式 | 注意事项 |
| --- | --- | --- |
| 词法 | 直接 `diag.Diagnostic` | 不中断，可多条 |
| 语法 | 解析器收集 | 期望 token/描述 |
| 语义 | `analyzer.errf` | 名称/类型/赋值/清理 |
| 代码生成 | 返回 `error` 文本 | 未支持构造；不新增语义码段 |
| FFI | `Diagnostic` + 源码片段 | 路径/行/列/码 |
| XPD | 词法/文法/语义 | 段落路径 |
| CLI | 用法/清单缺失 | 伪文件 `xnull` |

约束：

- 组件不直接写 stderr；
- 组件不拼最终文本；
- 组件不吞错误；
- 未支持构造必须有诊断/错误，不静默降级；
- 诊断消息不含内部治理/任务/角色信息；
- 诊断消息不泄漏凭据/个人数据。

---

## 7. 退出码映射

| 诊断类型 | 退出码 |
| --- | --- |
| 词法/语法/语义/构建失败 | 1 |
| 用法/清单缺失/未知旗标 | 2 |
| 中断 | 130 |
| 程序运行期 fatal | 134（子进程透传） |

说明：

- 工具链退出码与程序运行期退出码互不影响；
- `main` 返回非零按程序退出码透传；
- `fatal` 固定 134；
- 诊断本身不决定退出码，CLI/构建层决定。

---

## 8. 输出纪律

- 诊断写 stderr；
- 正常结果写 stdout；
- 不输出颜色/装饰（CI 稳定）；
- 不输出多行 message；
- 不输出完整调用栈（fatal 路径除外）；
- 不输出内部文件路径以外的实现细节；
- 不输出未转义的敏感值；
- 不把“建议”写成规则；
- 诊断必须可定位到文件/行/列（或伪文件/固定位置）。

## 9. 验证

| 用例 | 断言 |
| --- | --- |
| 词法错误 | 码/行/列/插入符 |
| 语法错误 | 期望 token 描述 |
| 类型错误 | 码/类型串/提示 |
| 清理错误 | ERR-205/206 |
| FFI 合同错误 | FFI-1xx + 片段 |
| XPD 错误 | 段落路径 + 行列 |
| CLI 错误 | CLI-00x + 退出码 2 |
| 排序 | 同一输入两次一致 |
| 无源码行 | 只输出 message/hint |
| 宽字符 | 列按标量计数 |

## 10. 边界

| 能力 | 说明 |
| --- | --- |
| warning/info 级别 | 当前不设；所有诊断为 error |
| 多行 span | 当前单行插入符 |
| JSON 诊断 | 未定义 |
| LSP 诊断 | 未定义 |
| 颜色 | 不输出 |
| 调用栈 | 只属于 fatal 路径 |
| 诊断国际化 | 当前中文文案；码稳定 |
