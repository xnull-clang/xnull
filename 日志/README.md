# 操作日志制度（Internal，不入公开空间）

**生效：2026-11-06，CEO 签发。全员适用：CEO、CTO、COO。**

## 规则

1. **每次操作必有日志**：不追求详细，但必须成块记录，一次操作一块。
2. **每块必含**：编号、日期时间、命令人→执行人、操作内容（1–3 句）、结果/状态。
3. **日志文件**：`日志/YYYY-MM/LOG-YYYY-MM-DD.md`，按天一文件；同一角色同一天多次操作在同一文件内追加。
4. **分工**：
   - CEO：记录自己的下达命令、验收、打回；
   - CTO：每完成一项任务、写回执的同时，在日志追加对应块；
   - COO：物料产出、同步、审计完成后追加对应块。
5. **块模板**：

```
### [序号] [角色] [一句话标题]
- 命令：谁下的令
- 执行：谁做的
- 内容：做了什么（简）
- 结果：完成 / 进行中 / 打回 / 阻塞
```

6. 交接依据：任务单、回执的编号与日志块编号对应，形成可追溯链条。
