# ABI v1 候选冻结（EXP-012）处置草案

- 日期：2026-11-07
- 来源：EXP-012（`收件箱/专家评审/评审意见-2026-11-07-v1.0.0.md`）
- 性质：工程状态标注，**不改变 ABI 语义**；新版本另存，不改母本。

## 1. 决定

`xrt.h` / `xrt_abi.c` 从“稳定 ABI v1”改标 **ABI v1 候选冻结**：

- 符号与签名可作为 codegen 与绑定层的冻结候选消费面；
- 候选期内允许修正字段/签名，不构成“稳定 v1”毁诺；
- 不在候选期发布对外 ABI 兼容承诺。

## 2. 转正判据（唯一）

numeric 变体（句柄 + Bytes + `@errorCode`）经 `xnull build` 端到端通过，并由 QA 复验。仅此一条，不以“设计完整”替代。
