### 5.3 已确认缺口（按严重度）

1. **编译器主链路未接入 FFI（阻断级）**
   - `impl/internal/codegen/` 全包没有任何 `internal/codegen/ffi` 的 import，`EmitCall`/`EmitSupport` 只被 ffi 包自己的测试调用。
   - `impl/internal/xfront/` 无 `FFICall` AST 节点，codegen 无对应分支——`ffi-contract.md §2` 的"codegen 遇到 FFICall 节点时调用"没有落地。
   - 影响：`.xfb` 校验与 emit 能力再完整，`xnull build` 生成的程序也调不到任何绑定入口。

2. **构建链路不链公开 ABI 与 XDK 原语（阻断级）**
   - `impl/internal/codegen/build.go:44-48` 的 cc 命令只链 `rt.c`、`rt_gc.c`、`rt_policy.c`、`rt_weak.c`，缺 `xrt_abi.c`、`rt_std_runtime.c`、`rt_std_text.c`、`rt_std_sys.c`。
   - 生成的 C 直接 `#include "rt.h"` / `"rt_gc.h"`（`codegen.go:27-28`），绕过 `xrt.h` 稳定 ABI，与 S7 §6.1 / INV-FFI-7（生成代码只经 `xrt_*`）不一致。
   - 影响：`xrt_*` 入口在真实产物中不可用；后续接入 FFI 包装时会缺符号。

3. **回调 trampoline 仅预留（功能缺口）**
   - `emit.go:174-175` `ErrTrampolineReserved`：`EmitTrampoline` 恒返回错误；依赖调度器栈 pin/根登记与 P-09 后的 codegen 回调钩子。
   - 台账 FFI-05 = 部分。

4. **返回/参数编组只覆盖标量、String、Handle（功能缺口）**
   - `emit.go:416`：返回类型落入 default 即报"编组未实现（M4.5c）"；`layout(c)` struct 值、数组/缓冲区返回没有 emit 路径。
   - 台账 FFI-02 = 部分。

5. **C 原语已就位但未进绑定（覆盖缺口）**
   - `rt_std_text.c` 导出 8 个 `xdkc_*`（parse_int/parse_float/format_int/fmt_append_raw/fmt_append_int/regex_match/utf8_to_utf16/utf16_to_utf8），`bindings/` 无对应 `.xfb`。
   - `rt_std_runtime.c:109` 的 `xdkc_env_get`（对应 `xdk.runtime.env`）、`rt_std_sys.c:142` 的 `xdkc_proc_status` 也未绑定（`sys.xfb:8` 明确"proc 暂不入绑定"）。
   - 影响：`test_std` 覆盖的能力大部分在 XNull 层不可达。

6. **公开 XDK 单元只有 text（覆盖缺口）**
   - `impl/lib/xdk/` 仅 `text.xn`，无 `sys.xn` / `runtime.xn` 包装层；`text.xn` 自身也标注"不含 extern/类/String 方法"，`@preview`。

7. **可空字符串语义未定案（合同缺口）**
   - `sys.xfb:7`：`dirRead` 迭代结束返回 NULL，XNull 侧可空映射"随 P-09 评审面确认"。

8. **构建入口无工程化封装（工程缺口）**
   - 只有 `build_rt.sh`；无 Makefile/CMake/CI 目标，无库产物（`.a`/`.dylib`），外部消费只能照抄脚本里的 cc 命令行。
   - `README.md:23-24` 记录本机 clang 17/macOS 的 ASan 运行时 SIGILL（环境故障），因此 ASan 不在验收基线内，内存安全验证只有逻辑断言，无 sanitizer 覆盖。

9. **诊断段位未与总台账完全对齐（流程缺口）**
   - `impl/docs/conformance/status.tsv` 中 FFI-02/04/05/06/07 仍为"部分"，且 FFI-04 指向的 `ffi_test.go` 与实现文件分布不一致（实现侧诊断码在 `check.go`）。

10. **Go 侧 codegen 核心测试未取得本轮结果（验证缺口，非失败）**
    - `go test ./internal/codegen/` 在本轮 300s 命令预算内未跑完（前一条 ffi 测试已耗 19s），未记录 PASS/FAIL；`evidence/.../8-go-codegen-test.txt` 为空。下轮单独留足时间复跑。
