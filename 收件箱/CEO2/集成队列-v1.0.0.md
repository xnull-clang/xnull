## 五、队列规则

1. **一个分支一个 owner**：冲突只由文件所有者解；他人只读。
2. **main 只进不出**：合入后若 QA FAIL，由 COO `git revert`，不由 QA/董事会直接改 main。
3. **SYNCED 才排下一合**：未回 `SYNCED <sha>` 的分支不进入合并队列。
4. **WIP**：同一 owner 同时只处理 1 个集成动作；B1 开工不与 P0 冲突时并行。
5. **证据**：每个动作必须有 commit sha + 命令 + 原始输出 + 未测项。
