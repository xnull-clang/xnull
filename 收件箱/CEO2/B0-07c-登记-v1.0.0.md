## 二、事实（main `9f5f66c`）

跑 B0-06 numeric 变体，`xnull build` 失败，关键报错：

```text
xnull: 提示：codegen：FFI 入口 fileClose 含错误码通道（@errorCode），P-09 本轮未接入 Result 映射（显式拒绝，不静默）（调用将报未定义标识符）
xnull: 提示：codegen：FFI 入口 fileOpenRead 的返回类型 File 未纳入 P-09（仅 void/Int/String）（调用将报未定义标识符）
xnull: 提示：codegen：FFI 入口 fileRead 含错误码通道（@errorCode），P-09 本轮未接入 Result 映射（显式拒绝，不静默）（调用将报未定义标识符）
... error[RES-101]: 未定义的名称 `Bytes`
... error[RES-101]: 未定义的名称 `fileClose`
```

证据：`evidence/SYNC-7df123d/b0-06-numeric-main-7df123d.out`、`b0-06-numeric-run.out`。

**根因范围**：P-09 当前只接入 `void / Int / String`；未覆盖 `File` / `Dir` / `Bytes` 返回或参数，以及 `@errorCode` → `Result` 映射。B0-07b 的文本 API（`readFileText`/`writeFileText`）已通过，不在此卡。
