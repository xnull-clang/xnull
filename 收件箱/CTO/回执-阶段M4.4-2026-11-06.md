## 二、4.4b 类 ✅

**产出**：`impl/internal/codegen/classes.go`、`classes_expr.go`；`impl/internal/interp/objects.go`；示例 `examples/classes.xn`

**codegen 侧**：
```
typedef struct { rt_header hdr; int64_t total; rt_string *label; } xn_Cls_Tally;
static const rt_type RT_TYPE_XN_Tally = { "Tally", sizeof(...), deinit, NULL };
static xn_Cls_Tally *xn_Cls_Tally_new(void);          // rt_arc_new + 字段初值
static int64_t xn_Cls_Tally_add(xn_Cls_Tally *self, int64_t v);
```
- 对象一律 ARC（`rt_arc_new`，M3 冻结 ABI）；String 字段由 deinit 释放；局部实例在作用域退出 `rt_release`
- 方法静态绑定（单态）；String 字段读写走 retain/release 纪律；`self` 直接映射首参

**解释器侧**（A 案交付）：
- `vObj` 值 + `objv{cls, fields, order}`；`new` 构造（字段初值按声明序求值、可引用 self）
- 字段读写（成员赋值错误消息化）、方法调用（self 绑定、ctrlReturn/ctrlErr 恢复、defer 走 execBlock）
- 协议分派按实际类的方法名解析（vtable 属 codegen 实现细节）
- **不做 ARC 时序模拟**：对象由 Go GC 托管，deinit 不自动触发——与批注边界一致

**验证（现场可复跑）**：
```
$ xnull build examples/classes.xn -o /tmp/bin_cls && /tmp/bin_cls > a.txt
$ xnull run --interp examples/classes.xn > b.txt
$ diff a.txt b.txt   # 无输出 → 逐字节一致
```
输出：`0 / 5 / 5 / 15 / 15 / tally / 3 / 30 / 2 / 85`，退出码双方 0。

## 三、4.4c 边界（按 CEO 指示给理由）

闭包/元组**不在自举子集内**：M5.1 子集以「类 + 容器 + 既有四示例面（Int/Bool/String/Result/defer/if/while/for-in/函数/类/容器）」为界，自举代码不出现闭包与元组字面量即不阻塞；codegen 对两者保持显式报错（`Float`/`Char`/`null` 同理），不静默降级。若 4.4c 在实际自举编码中出现需求，按需补并回执。

## 四、明确边界（不虚报）

| 未支持项 | 表现 |
| --- | --- |
| 继承（`class A : B`） | sema 允许声明，codegen 显式报错"继承暂未支持" |
| 协议实现/协议变量多态 | codegen 显式报错；解释器按名分派已可跑 |
| 带参主构造器 | codegen 显式报错（解释器已支持 `class X(final Int id)` 绑定） |
| 容器字段 / 类引用字段 | codegen 显式报错 |
| 对象打印 | 不支持（`print(obj)` 报错） |

以上均为 M5 GC 类型/继承批次的前置接线点，非缺陷隐瞒。
