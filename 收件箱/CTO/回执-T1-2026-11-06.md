## 交付内容

`impl/internal/interp/`——tree-walking 解释器（约 700 行），基于既有 Go 前端
（4a 词法 → 4b 表达式 → 4c 语句 → 4d 编译单元，四级齐备）。

- 命令：`go run ./cmd/xnull run examples/hello.xn` 一条命令出结果 ✓
- 内置函数 2 个（≤ 3）：`print(x)`、`str(x)`；`Ok`/`Err` 是语言构造器非内置 ✓
- 支持语义：顶层函数/字段、控制流（if/while/do/for-in 区间/switch 无隐式贯穿/
  break/continue 含标签）、赋值与复合赋值、字符串插值、`??`、逻辑短路、
  **Result/Ok/Err/try 传播（S1 §10.1—10.2）**、**defer/errdefer LIFO（§10.3）**、
  **throw fatal 不执行 defer（§10.4）**

## 验收证据

```

```

### 2. 确定性：多次运行逐字节一致

- `internal/interp/interp_test.go` 的 `TestDeterminismByteIdentical`：同源程序连跑 5 轮逐字节比对，通过
- `internal/cli/cli_test.go` 的 `TestRunSingleFileDeterministic`：CLI 级两次运行比对，通过
- `examples/` 三个示例各跑两轮 diff 为空（见 T2 回执）

### 3. Result/try/defer 实测输出

```
$ xnull run examples/defer-cleanup.xn
A
B
C
inner cleanup        ← 块退出即执行（§10.3 作用域时机）
```

## 范围声明（不做静默扩展）

解释期**不做静态类型检查**（名称解析 §3.3、确定赋值 §5.3、类型检查 §2.6 属语义分析切片）；

"解释器不支持"诊断，不静默。全部不支持项已写入 `impl/README.md`。
