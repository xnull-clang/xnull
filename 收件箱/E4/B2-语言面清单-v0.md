## 2. 逐项清单

### 2.1 闭包（S1 §7.7）

- [ ] **CG-CLOS-1 表示**：函数值 = GC 对象 `xn_closure { fn, env }`；无捕获时复用静态实例。
- [ ] **CG-CLOS-2 捕获**：按引用捕获局部/参数/`self`；捕获变量提升为堆 cell；多闭包共享同一 cell；嵌套闭包共享外层 cell。
- [ ] **CG-CLOS-3 体形态**：块体与单表达式体等价（表达式体降级为 `return expr;`）。
- [ ] **CG-CLOS-4 立即调用**：`((Int x) -> x + 1)(1)`。
- [ ] **CG-CLOS-5 闭包返回 `Result`**：`try`/`defer`/`errdefer` 的作用域止于闭包，不穿透外层。
- [ ] **CG-CLOS-6 泛型实参**：闭包可存入容器/字段/元组；闭包类型可作为 `Result` 实参。
- [ ] **CG-CLOS-7 诊断**：无目标类型的空 `[]`/`null`/无目标闭包不能用于 `var`（sema 已有，codegen 需拒绝而非崩溃）。
- 依赖：E5 GC 对象头与 cell（S3）；E2 捕获分析定稿。

### 2.2 函数值（S1 §2.5、§7.10）

- [ ] **CG-FN-1 类型映射**：`R(P...)` → 闭包指针类型；`void()` 合法；函数类型是引用类型、默认 `null`。
- [ ] **CG-FN-2 签名相等**：参数/返回完全一致才可赋值（sema 已做，codegen 仅消费结论）。
- [ ] **CG-FN-3 调用**：`f(args)` 经闭包 `fn` 指针调用；参数按位置；`Result` 返回走既有映射。
- [ ] **CG-FN-4 null 调用**：panic（与 S4 §7.2 退出码映射一致）。
- [ ] **CG-FN-5 顶层函数作值**：`Int(Int) g = add`（函数名到闭包值的转换）。
- [ ] **CG-FN-6 重载**：函数值取用时按目标签名选重载；歧义报错（不在 codegen 自选）。

### 2.3 递归（S1 §4.1、§8）

- [x] **CG-REC-1 顶层直接递归**：已通过（原型前置，S1-06）。
- [x] **CG-REC-2 顶层相互递归**：已通过（S1-06 多文件前向声明）。
- [ ] **CG-REC-3 泛型递归**：单态化后按实例递归；实例去重。
- [ ] **CG-REC-4 终止检测**：无限展开必须报诊断（S1 §8.1「递归单态化必须终止」），禁止静默截断；实现可设深度上限。
- [ ] **CG-REC-5 闭包自递归**：语言只保证顶层递归；闭包自引用经捕获变量（需确认 S1 冻结文本，不在本清单预设语义）。
- 依赖：B2 单态化卡（与 G11 泛型形态同一根因）。

### 2.4 错误恢复（S1 §10、S4）

- [ ] **CG-ERR-1 Result 泛化**：`Result<T,E>` 支持全部合法 `T`/`E`（现仅 `Int/Bool` + `String`）。
- [ ] **CG-ERR-2 `try` 任意表达式位置**：实参、return、二元、插值、容器元素、闭包体；失败路径执行本层 `defer`/`errdefer` 并返回错误。
- [ ] **CG-ERR-3 作用域清理一致性**：成功/`Err` 返回/`try` 传播三路径清理行为一致（S4 §8，MEM-10）。
- [ ] **CG-ERR-4 `@mustUse`**：`Result` 裸表达式丢弃在 sema 拒绝（已有），codegen 不得生成静默丢弃。
- [ ] **CG-ERR-5 `main` 禁 `try`**：`main` 不能返回 `Result`（S4 §7.2），入口只做退出码映射。
- [ ] **CG-ERR-6 `throw` 与 `errdefer` 交互**：fatal 路径不执行 `errdefer`（S1 §10.3）。
- [ ] **CG-ERR-7 闭包内错误恢复**：错误只从闭包返回；闭包目标类型非 `Result` 时 `try` 为编译错误。

## 3. 建议卡序（开工后）

| 卡 | 内容 | 依赖 | 验收向量 |
|---|---|---|---|
| B2-01 | 函数类型 + 顶层函数作值 + 调用 | 无 | `apply(add,1)`、`void()`、null 调用 panic |
| B2-02 | 闭包表示 + 无捕获/单层捕获 | B2-01、E5 cell | 计数器、`add`/`inc` 等价、立即调用 |
| B2-03 | 嵌套闭包 + 共享 cell + `self` 捕获 | B2-02 | 双层计数器、两个闭包共享计数 |
| B2-04 | 泛型单态化 + 递归终止检测 | B2-01 | `identity<Int>`、`boxFirst<Int>`（G11 泛型形）、无限展开诊断 |
| B2-05 | Result 泛化 + `try` 任意位置 | 无 | `try` 于实参/return/插值；三路径清理 |
| B2-06 | 闭包内错误恢复 | B2-02、B2-05 | 闭包 `try` 不穿透；`errdefer` 触发边界 |
| B2-07 | 双路径对照与差分 | 全部 | 解释器 vs 编译产物 stdout/exit 一致 |

## 4. 明确不做（B2 范围外）

- 折行 / 声明间空行 / import 分组（R14，属 B1 不做项）。
- 约束、默认类型实参、泛型闭包（S1 §8 明确不支持）。
- `catch`/`finally`、跨帧异常（S1 §0.6 不支持）。
- 按值捕获语法、弱捕获（S1 §7.7 不提供）。

## 5. 交接
