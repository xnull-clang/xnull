- 卡片：S3-05（ADR-007 卡序：协议字段指向 GC 对象的 scan/释放、Any/Object 装箱、含引用元素元组 scan/deinit）
- 提交：`32159cc`（仅 pod/e4-codegen，未 merge main）
- 顺序：先红后绿（`s3_05_test.go` 初始 4 例全红；实现后全绿）。

## 一、红 → 绿

| 用例 | 修前（红） | 修后（绿） |
|---|---|---|
| 协议字段（GC 类持 `P`） | `isProto` 只进 `isRefField`；scan 仅遍历 `isCls`；GC 类 deinit 直接 `rt_release(o->p)` | scan 生成 `visit(o->p)`；GC 类 deinit 跳过协议字段，由 sweep 释放 ARC 实现 |
| `Any a = 42 as Any; a is Int; a as? Int` | `Any` 无 cType/无装箱，codegen 报「类型 Any 未支持」 | `xn_Any *` GC 盒；`xn_box_int`；`is` 比较动态类型名；`as?` 拆箱取 `i` |
| `Any` 字段（拥有者 GC） | 无字段形态 | 字段为 `xn_Any *` 槽，纳入 scan（`visit(o->v)`），赋值/初值不计数 |
| `(Int, String)` 类字段 | 无 scan/deinit 处理 | deinit `rt_release((o->p).f1)`（String 由 deinit 释放） |
| `(Int, C)` 类字段 | 同上 | GC 类 scan `visit((o->q).f1)`；deinit 不重复释放（sweep 释放 ARC） |

回归：`go test ./internal/codegen/... ./internal/cli/ ./internal/interp/ ./internal/sema/ -count=1` 全绿。

## 二、实现要点

- **协议字段**（`classes.go`）：`f.isProto && ci.isGC` 加入 scanFields；deinit 对该组合跳过
  `rt_release`；ARC 类保持原有释放规则（协议字段是 ARC 强引用）。
- **Any/Object**（`any.go` + prelude）：
  - `cType("Any"/"Object") → xn_Any *`；prelude 定义 GC 盒 `xn_Any` 与
    `RT_TYPE_XN_ANY`（scan 访问 String 与对象载荷）、`xn_box_int/int32/bool/str/obj`、
    `xn_any_is`、`xn_any_get_int/str/obj`。
  - 装箱：`x as Any/Object`；对象类型名取运行期分配头 `hdr.type->name`（动态类型），
    ARC 载荷 retain 一份、GC 载荷不计数；`new C() as Any` 装箱后释放构造所有权。
  - 拆箱：`is` 比较类型名；`as?` 不匹配返回 0/NULL；`as` 不匹配 `rt_fatal`
    （进程终止，与 §14 fatal 口径一致）。String/类拆箱各取得一份新引用。
  - 局部/字段：Any 是 GC 引用，不做 retain/release；Any 字段由 scan 追踪。
- **元组引用**（`tuple.go`）：`tupleRefPaths` 递归收集元素路径；GC 类 scan 按路径
  `visit` 类/协议/数据枚举元素；deinit 按路径释放 String/句柄/Bytes；元组结构体定义
  移到类前向声明之后，支持 `(Int, C)` 这类类元素。
- 数据枚举/单例/泛型类字段同步标记 `isAny`。

## 三、边界

- `Any` 拆箱到**协议**目标暂未支持（需 vtable/实现检查元数据，归 B2）；装箱与
  `is`/`as?` 支持 Int/Int32/Bool/String/类/数据枚举/句柄/Bytes。
- `is` 比较采用**精确动态类型名**（`hdr.type->name`），不做继承链祖先匹配；
  `Any a = (Sub as Base) as Any; a is Base` 记为 false。祖先遍历需运行期类型元数据，
  归 B2 类型系统切片。
- Any 盒为 GC 对象，局部变量根（栈根）仍属 P0-4/S3-02 范围；本卡不做栈根登记。
- 协议字段 deinit 跳过释放仅对 GC 拥有者生效；ARC 类协议字段保持原有引用计数规则。
