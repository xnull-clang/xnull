## S3-07（d433715）：FFI trampoline

**先红**：`TestTrampolineGenerated` 在旧实现上返回 `ErrTrampolineReserved`（`evidence/S3-07/red.log`）。

**实现**
- 运行时新增 `xrt_callback_env`：GC 对象；`new` 登记 `rt_gc_root_add`、`destroy` 注销（幂等）；
  已注销/空 env 调用 `xrt_fatal`；`invoke` 调 `xrt_callback_fn(closure,args,nargs,result)`。
- `EmitTrampoline(entry)` 生成 `xn_tramp_<entry>_new/_destroy` + 调用跳板；删除
  `ErrTrampolineReserved`。
- `test_std.c::test_callback_env` 覆盖生命周期与注销后调用终止（fork）。

**后绿**：`TestTrampolineGenerated` PASS；六套件 exit 0；ffi 包全绿。

**边界**：语言闭包 codegen 未落地，目标 ABI 由绑定层 `xrt_callback_fn` 提供；
env 的 GC 回收在销毁后的下一次收集。

## S3-08（153be78）：诊断/选项/指标

**先红**：3 例（策略覆盖/统计发射/统计运行）在未接线时失败（`evidence/S3-08/red.log`）。

**实现**
- 运行时 `rt_stats` + `xrt_stats_*`：allocs/frees/bytes/gc_collections/gc_freed；默认关闭；
  `xrt_stats_report` 单行 stderr。
- `Options.MemPolicy`（auto/arc/gc）与 `Stats`；`EmitCWithBuildOptions` 强制类分配种类，
  `--stats` 在 main 包装打开统计并在收尾输出。
- CLI：`xnull build file.x --mem=auto|arc|gc --stats`（flag 在 `.x` 之后）。
- `test_std.c::test_stats`；`mem_s308_test.go` 3 例。

**后绿**：3 例 PASS；六套件 exit 0；codegen/ffi/cli 全绿；
`--mem=arc` 环类 `rt_arc_new`（live=2/gc_freed=0），`--mem=gc` 非环类 `rt_gc_new`
（live=0/gc_freed=1），`--stats` 输出指标。

**边界**：`--mem` 只覆盖类（枚举/单例固定 GC）；逃逸转储未做（S3 盘点 P0-5）；
bytes 为累计分配，释放不扣减。
