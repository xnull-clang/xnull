## 一、红 → 绿

| 用例 | 修前（红） | 修后（绿） |
|---|---|---|
| `Context c = Context.background()` | 类型 Context 未支持 | `xrt_context_background()` |
| `TaskGroup.create(c)` | 未支持 | `xrt_task_group_new(ctx)` |
| `g.spawn(() -> {...})` | 闭包/任务未支持 | 生成 `xn_task_body_N` + env 装箱 + `xrt_task_group_spawn` |
| `t.join()` / `g.close()` | Result 成员 TaskError 未支持 | `xrt_task_join`/`xrt_task_group_close` → 内联 `Result<T,TaskError>` |
| 捕获对象 | 无 env/scan | `xn_task_env`（GC）+ `xn_task_env_scan` 访问 refs |
| 任务结果 GC 对象 | 无根 | body `xrt_task_root_bind`，join `xrt_task_root_unbind` + `xn_root_add` |
| 挂起点/发布点 | 无 | 任务体入口/出口、spawn、join/close 发 `xrt_safepoint()` |

## 二、实现要点（只改 codegen/发射，runtime 零改动）

- **类型**：`Context/CancelToken/TaskGroup/Task<T>/TaskError` → `xrt_*` 句柄；
  `TaskError` 复用 `xrt_error_kind`（S5-00 §八）；`Result<void,TaskError>` 值槽占位。
- **任务闭包**：零参 lambda 生成 `int32_t body(void *env, xrt_context *ctx,
  xrt_task_result *out)`；`return Result` 翻译为 out.ok/value/kind/error。
- **env GC 与 scan**：`xn_task_env` 用 `rt_gc_new_size` 分配（refs+vals 内联）；
  scan 遍历 refs。捕获分流：引用 → refs（ARC 捕获 retain，env 清扫由 scan
  release；GC 不计数）；标量 → vals；`Result<标量,TaskError>` 展开 3 槽。
- **任务根**：env 根由 runtime spawn/unbind（S5-00 §7.1）；任务结果中的 GC 引用
  由 codegen 在 body 出口 `xrt_task_root_bind`，join/close 侧 unbind，并把值
  登记到调用方根帧（S3-02）。
- **挂起点/发布点**：body 入口/出口、spawn 后（env 发布）、join/close 后（结果
  发布）调用 `xrt_safepoint()`（S5-00 §7.2/§7.6）。
- join 映射：`rc != 0 → Err(kind=rc)`；`!tr.ok → Err(kind=tr.kind)`；否则 Ok
  （标量按 intptr 装箱/拆箱，引用直传）。

## 三、边界

- 任务闭包当前支持**零参 lambda**；带参闭包、捕获结构体/元组、捕获 Result 含
  引用字段 → 显式报错（后续闭包批次）。
- `TaskError` 仅携带 kind（`xrt_error_kind`）；业务错误值指针/error 字段固定 NULL。
- spawn 失败按合同 fatal（S5-00 §三）；joinDeadline 仅透传 deadline 参数，
  取消/超时机制随 S5-02。
- 并发 GC（原子弱表/写屏障）仍属 S3-06；本卡只做单载体线程下的根/发布点。
