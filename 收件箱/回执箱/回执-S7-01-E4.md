## 一、红 → 绿

| 项 | 修前（红） | 修后（绿） |
|---|---|---|
| Text 参数/返回 | `类型 Text 未支持`（调用点无编组） | Text 以 bytes/len 借出；返回经 `xrt_text_from_string` |
| layout(c) 参数 | layout 类型未投射 | XNull 结构值临时 + `(xn_layout_X *)&tmp` |
| 标量数组 `Int[]` | 数组参数未编组 | 容器实例化 + `data/len` |
| Float/Float32/Float64 | 标量白名单拒绝 | C double/float 编组 |
| Char / UInt / 定宽整型 | 未支持 | 按 S7 §3.2 C 宽度编组 |
| `.transfer` 句柄 out | 句柄参数按值传，签名不匹配 | 传 `xrt_handle **`，包装层写回 |
| Bytes `.transfer/.reclaim` | 包装层拒绝「需分配器合同」 | 显式所有权转移（不经 canary） |
| layout 尺寸检查 | 只生成 `_check` 函数未调用 | `_Static_assert(sizeof(xn_layout_X) == N)` + sema 尺寸登记 |

端到端输出：`3 / 9 / 6 / 3 / true / 5 / 2 / 2 / 0 / true`（Text、layout、数组、
Float、Char、UInt、Bytes transfer/reclaim、句柄 out）。

## 二、实现要点

- **sema 投射**（`s701.go`）：`RegisterFFIProjection(reg)` 把 layout（字段+ C 尺寸，
  与发射共用自然对齐计算）与入口（Type/Lease/Out）登记给 sema；句柄 out 参数按
  可空句柄登记（`Handle?`），transfer/reclaim 触发「实参必须是变量」检查。
- **包装发射**（ffi/emit.go）：Text 参数 `(bytes,len)`、Text 返回；Bytes transfer/
  reclaim 不再拒绝；layout `_Static_assert` 尺寸检查。
- **调用点**（ffi_gen.go）：Text 经 `xrt_text_to_string` 取字节视图；layout 结构
  值临时转指针；数组按元素类型实例化容器并传 data/len；标量全表映射；句柄
  transfer 传 `&var`；Bytes 统一 data/len。
- 兼容：`ffiParamXType` 句柄参数统一可空（File?），既有 File 实参可赋给 File?；
  旧「Bytes 移交未覆盖」测试按新支持更新。

## 三、边界

- 数组元素限标量/layout（S7 §3.5）；引用元素数组仍拒绝。
- 句柄 out 的 `.transfer` 所有权由包装层 `xrt_handle_new` 接管；`.reclaim` 按
  归还闭合（`xrt_handle_mark_closed`）。
- layout(c) 尺寸检查为编译期断言；嵌套 layout 按依赖顺序登记。
- Text 返回要求原生返回 NUL 结尾 C 串（与 String 同约定）。
