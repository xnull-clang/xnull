## 已落地

- `xnull build`（无 .x 参数）走清单模式：validate→compile→test→package→install。
- `--skip <stage>` / `--skip=<stage>`；阶段限 validate/compile/test/package/install。
- build 字段：`mode`（debug/release/size，映射 -O0/-O2/-Os）、`warnings`
  （default/strict，校验）、`sourceRoot`/`testRoot`、`entryFile`/`entryPackage`；
  未知 build 字段/非法取值/`sourceRoot` 指向 `target/` → 退出码 2。
- 入口解析（S8 §5.4）：entryFile+entryPackage / 仅 entryFile / 缺省
  `src/main/x/main.x`；缺文件、无/重复 main、entryPackage 不匹配 → 退出码 2。
- 产物：`target/<artifactId>-<version>` + `target/<artifactId>-<version>.xmeta`；
  编译先到 `target/.cache`，测试通过后 package。
- `.xmeta`：坐标、platform、xdkVersion、languageVersion、toolchainVersion、
  profiles、plugins、lockSha256、inputs（清单/入口/锁/工具链摘要）；固定顺序，
  两次构建字节一致。
- 退出码：清单/文法/用法 → 2；编译/测试失败 → 1；成功 → 0。
- `xnull run` 清单模式：构建后运行产物并透传退出码；`xnull test` 跑 validate→compile→test。
