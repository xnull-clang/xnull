## 一、格式对齐（与 E6 S8-01 一致）

直接复用 `impl/internal/xpd` 的 AST（lexer/parser），按第 8 部分 §7 读取：

```xpd
project {
  ...
  link {
    unsafe = true
  }
}
```

- 路径：从入口文件所在目录向上查找 `xnull.project`（工程根）。
- `link` / `unsafe` 缺省 → `false`（S8 §7 缺省值）。
- 值仅接受裸词 `true` / `false`；其他值、重复 `unsafe` 字段 → 构建失败。
- 不新增清单语法、不另写解析器；E6 S8-01 的 schema/诊断落地后字段语义不变。

## 二、红 → 绿

| 项 | 修前（红） | 修后（绿） |
|---|---|---|
| `link.unsafe` 解析 | 清单未读，门禁不存在 | 读 `project.link.unsafe`，缺省 false |
| 未开启时构建 | 含 `@unsafe` 入口照常构建成功 | 无清单 / `unsafe=false` / 缺省 → 退出码 1 |
| 合同文本必填 | 已有 `FFI-110` | 保留并由门禁测试复核 |
| 仅 `bindings/` | 已有路径校验 | 保留；`src/*.xfb` 的 `@unsafe` 报 `FFI-110` |
| 应用代码不可创建 | 语言层无 `@unsafe` 语法，但无机械用例说明 | 以 `src/` 下 `.xfb` 负例固化（FFI-04） |
| 启用后构建日志 | 无记录 | stderr 记录 `link.unsafe=true` 与受控入口名（S8 §7 强制） |

## 三、实现要点

- `impl/internal/codegen/unsafe_gate.go`
  - `findProjectRoot`：入口目录向上查找 `xnull.project`。
  - `readLinkUnsafe`：`xpd.Parse` → `project` → `link` → `unsafe`；默认 false，严判重复/非法值。
  - `checkUnsafeGate`：仅当注册表存在 `Entry.Unsafe` 时生效；未开启返回错误，
    启用时写 stderr 构建日志。
- `impl/internal/codegen/build.go`：`BuildWithOptions` 在 FFI 加载后、注入前调用门禁，
  文件模式与后续清单模式共用同一入口。
- 声明层不重复实现：`ffi.Load` 继续负责「仅 bindings/」与合同文本非空（`FFI-110`）。
