# 回执：S6-09b XDK-09 补口（E4）

- 结论：**已提交可用版本**；修复 QA 两项失败。
- 证据：`evidence/S6-09b/green.log`
- 红（QA 原报告）：`返回表达式 *xfront.Member 未支持（M4.1）`；生成代码缺
  `xdkc_socket_*`（net 运行时链接失败）。

## 修复

1. **Member 返回**：`emitReturn` 增加成员返回值分派（标量/枚举/String/Bytes），
   `bytesExpr` 支持 Member；net.x 的 `return self.errorKind/self.message/
   self.payload` 可发射。
2. **绑定符号对齐 E5**：`bindings/xdk/net.xfb` 与 `rt_std_net.c` 采用 E5 实际符号
   `xdkc_socket_{connect,send,recv,close}`、`xdkc_http_request/status/body_text/
   response_close` 及 `*_async`；`s609.go` 改调 `xdkc_socket_*_async` /
   `xdkc_http_request_async`，生成前向声明补入包装 ABI 头。
3. **容器 typedef 顺序**：容器 typedef 提前到类/函数原型之前；预登记签名与
   Result 成员容器；Map helper 尊重 `skipDecl`，避免重复 typedef。
4. **net.http/Class 面**：sema 恢复 E1 net.x 的 `connect/connectAsync/bind/.../
   get/getAsync/post/postAsync` 签名；保留 E5 FFI 面（socketConnect/httpRequest 等）。
5. **String 返回**：FFI 包装 String 返回值类型改为 `rt_string *`（与生成代码一致）。
