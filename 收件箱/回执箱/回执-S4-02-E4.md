## 二、实现要点

- **Result 任意 E**：`resultName` 登记实参；`resultInfo` 解析 v/err C 类型（Int/
  Bool/String/Int32/类/结构体/枚举/ErrorKind）；typedef 按实际 err 类型发射；
  `Err(e)` 按 E 类型求值（String/类/结构体/枚举）；`error()`/`value()`/`unwrapOr`
  类型与发射统一。
- **ErrorKind**：`import xdk.errors` 时注入内建简单枚举（14 项，0..13 对齐
  `XRT_ERR_*`）；`ErrorKind.X` / 枚举名打印走既有简单枚举路径。
- **wrap**：`wrap(r, e)` → 先求值 r 与 e（eager，保持实参求值语义），失败时
  `t.err = e`；成功原样返回。
- **mapErr**：`mapErr(r, f)` → Ok 原样拷贝到目标 Result；Err 调 `f(r.err)` 并
  赋给目标 E2。转换函数仅支持顶层函数（闭包未实现）。
- **report**：返回原 Result（XDK 定案 3-a-1）；失败时调用生成前置
  `xn_report_line(kind, describe)`：栈缓冲 + `write(2)`、控制字符折叠、单行、
  无 malloc；kind 名走 `xrt_error_kind_name`。支持语句形态与 `return report(r)`。
- 顺带修复：结构体同名构造调用识别（`new E(..)` 之外的发射路径）；结构体
  self 值语义字段访问（`.`）。

## 三、边界

- 协议类型 E（`Result<Int, Error>`）暂未支持：需要内建 Error 协议 vtable 元数据，
  归 S4-02 sema/协议批次。
- `mapErr` 的转换函数仅支持顶层函数（codegen 闭包未实现）；Lambda 实参显式报错。
- `report` 的 E=String（过渡错误串）按 `Internal` 分类输出；正式路径要求 E 实现
  `kind()/describe()`。
- Result 为内联值：Err 的引用载荷共享指针，无盒身份、无额外 GC 分配。
