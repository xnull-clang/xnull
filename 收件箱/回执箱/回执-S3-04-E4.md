## 二、实现要点

- **类型**：`Text → xrt_text *`、`StringBuilder → xrt_sb *`（`cType`）。
- **发射**（`s304.go`）：Text 静态构造 `Text.fromString`、实例 `length/codePointCount/toString/compareTo`；
  StringBuilder `StringBuilder()`、`append(String/Int/Bool)`、`length`、`toString`；
  字符串拼接/格式化仍走既有 String 助手，定长分配改 `rt_string_alloc`（运行时决定 ARC/GC）。
- **GC 判定**：`isGCTypeC`/`isGCRootC` 纳入 `String/Bytes/Text/SB`；类 scan 访问
  String/Bytes/Text/SB/容器字段及元组内同类元素；容器元素分流按 GC（不计数、只扫描，
  字面量/remove 不再释放 GC 元素）。
- **根登记**：完全复用 S3-02 根帧（局部/参数/全局字段 → `xn_root_add`/`xn_root_hold`），
  没有新增第二套根机制；Text/SB 字段初始化/赋值走 GC 引用路径。
- **命名对齐**：scan 钩子改为 `*_gc_scan`（与 E5 分支一致，降低合并冲突）。

## 三、与 E5 / S3-02 的边界

- 不修改运行时、不复制 E5 的 rt_gc/xrt 变更；只按 E5 分支 `xrt.h`/`rt_gc.h` 合同发调用。
- 根逻辑与 S3-02 共用：`xn_root_hold/release` 持有计数表保证 String 与类/容器共享根时不误删。
- Text/SB 运行用例按 `xrt.h` 是否含 `xrt_sb_new` 自动 skip：本 pod（main 运行时）skip，
  E5 分支上必须 PASS（已 PASS）。
