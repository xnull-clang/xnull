# 回执：B2-04d codegen 修差异（E4）

- 结论：**部分完成**。token 0 差异、diags 0 差异、AST 37/39；
  剩余 `xdk/text.x`、`xnfmt.x` 两个大文件在 GC 开启时原生崩溃（GC 关闭时 AST 与 Go 逐字节一致）。
- 证据：`evidence/B2-04d/{native-diff.tsv,red.log,green.log}`

## 已修根因

1. **接收者重复求值**：`self.next().text` 类方法调用在
   `recvCName` 中被求值两次，导致解析器位置跳格（`Int` 被当 `main`、Name 空）。
   现在按语句缓存接收者临时值，`next()` 只执行一次。
2. **GC 局部重赋值丢失根**：`ret = self.parseType()`（在嵌套块内）先加根，
   块退出 `root_restore` 又把新值根移除；随后 `parseBlock` 触发 GC 收集，
   `ret` 变空 → `(Ret )` / `Qual "main"` / Name 空。
   现在跨作用域赋值改为 `xn_root_release(旧) + xn_root_hold(新)`，
   在声明作用域退出时释放；同作用域赋值仍走 `root_add` + 块恢复。
3. 附带：类返回 Member（B2-04c 已入）。
