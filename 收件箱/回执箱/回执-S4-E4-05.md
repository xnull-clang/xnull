## 一、验收用例与结果

### BOUND-01 进程级退出码（编译产物）

| 情形 | 期望 | 结果 |
|---|---|---|
| 正常返回 | 0 | PASS |
| 返回非零（42） | 42 原样 | PASS |

| 显式 throw | 134，之前 stdout 保留 | PASS |
| `static void main` | 0 | PASS |

### BOUND-02 Result 不跨界

- `.xfb` 参数位 `Int32 f(Result r)` → 诊断点名「Result 不跨语言边界」；
- 返回位 `Result g()` → 同样拒绝；字典不产出入口。

### CLEAN-01 errdefer 补偿 / 部分完成

- 多步注册 `errdefer` → 失败时按 **LIFO** 补偿（`close:b` → `close:a`）；
- Ok 路径不执行 errdefer；
- 原错误 `boom` 不被补偿动作覆盖；
- 部分完成回滚：`State.n` 经两次 `inc` + 两次 `errdefer dec` 后归零；
- `try` 逐层传播触发各层 errdefer。

### FFI 边界错误路径

- `@errorCode(codeParam = .code)` 出参非零 → `exit(134)`，入口不继续；
- 已映射码（`7 = NotFound`）→ stderr 报 `NotFound`；
- 未知码（9，无映射）→ `Internal`（**绝不映射为 Ok**，S4 §7.3）；
- 错误码分类由生成的 `xn_ffi_<region>_error_kind` 提供。

## 三、边界（如实说明）

- BOUND-03（取消/超时映射）归 S4-04 + B3，本卡未覆盖；`Cancelled/Timeout`
  运行时未落地，不能假测。
- `@errorCode(codeParam = .result)`（错误码即返回值）形态按 S7 合同把 rc 交给
  调用方，本卡只验证出参形态的 fatal 路径；返回值形态的 ErrorKind 转换随 S4-04。
- CLEAN-01 的「补偿本身失败」无法用 `errdefer` 语句表达失败（无返回通道）；
  若补偿 `throw` 则按 §10.4 fatal 终止，不展开补偿，属既有语义。
