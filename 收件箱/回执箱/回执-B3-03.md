## 实现

`impl/lib/b3/xnullc.x` 扩展：

- **Result**：按类型动态插入 `typedef struct { int ok; T v; E err; } xn_Result_T_E;` 与顶层函数原型；`Ok`/`Err` 返回 `xn_ret = (T){...}`。
- **成员**：`isOk`→`.ok`、`isErr`→`!....ok`、`value`→`.v`、`error`→`xn_result_error_copy_rt(.err)`、`unwrapOr`→`(.ok ? .v : d)`。
- **try**：`T t = call; if (!t.ok) { xn_ret = t; restore; cleanup; return xn_ret; } <elem> v = t.v;`。
- **defer/errdefer**：注册时分配临时编号，函数/块退出按 LIFO 内联；块级 defer 在块退出执行；`errdefer` 包 `if (!xn_ret.ok)`；early-return 路径同时执行块/函数 cleanup。
- **throw**：字符串临时 + `xn_throw(t);`。
- 顶层函数参数映射 `xn_p_<name>`，Result 函数使用 `xn_ret`；prelude 按 Result/List 动态拼接。
