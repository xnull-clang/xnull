# 回执：S7-01 sema 面

- **状态**：`DONE`（sema；发射由 E4 接）
- **调用点类型**：新增 `sema.RegisterFFIEntries`，支持 `Text`/layout 名/`Int[]`/`Float`/`Char`/`UInt`/`Bytes`/句柄；实参与返回按签名检查。
- **所有权形态**：`.transfer`/`.reclaim` 参数与句柄 `Out` 形参必须是变量（禁止临时值）；`.transfer` 句柄 out 按 `Handle?` 返回类型检查。
- **layout 尺寸**：新增 `sema.RegisterExternalLayout(name, fields, cSize)`，按 C 自然对齐计算 sizeof 并与 C 侧 `cSize` 核对，不一致返回 error；`LayoutSize` 可查询。修正定宽标量（Int8..UInt64/Float32/64）可作为 struct 值字段（S7 §3.2/§3.3）。
- **测试**：`s7_01_test.go` 覆盖 Text/layout/数组/Float/Char/UInt、句柄 out、Bytes transfer/reclaim、layout 合法/非法尺寸；红→绿 `evidence/S7-01/`；sema/xfront/interp/codegen/cli 全绿。
- **E4 接口**：`handoff/S7-01-sema.md`（`.xfb` → `FFIEntry`/`FFIField` 映射、登记顺序、sizeof 责任）。
