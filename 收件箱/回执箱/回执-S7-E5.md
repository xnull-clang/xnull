# 回执：S7 FFI 盘点（E5）

- 执行位：运行时线 E5
- 基线：main `44d7681`
- 性质：**只盘点**，未改代码/绑定/运行时
- 产出：`收件箱/门/S7盘点-E5.md`
- 结论：FFI 底座过半；主要缺口在 codegen 调用点消费、错误码→Result、
  trampoline 集成、`@unsafe` 门禁、长阻塞伴生路由、ABI 转正

## 盘点要点

1. **已有资产**
   - `.xfb` 解析/合同校验：`FFI-100`—`FFI-111`，租约/transfer/reclaim/layout/错误码/阻塞/unsafe。
   - 包装生成：`EmitSupport/EmitCall`，标量/String/Bytes 借出/数组/layout/句柄 transfer/reclaim/canary/错误分类。
   - 运行时 ABI：`xrt.h`/`xrt_abi.c` 分配/计数/弱表/根/安全点/任务根/句柄/错误/回调 env。
   - trampoline 生成器与运行时 env 均在；`@longRunning` 伴生校验在；阻塞清单与注册表同步。
   - 现有绑定 20 入口（runtime 6 + sys 13 + text 1），全部有 `@blocking`。

2. **主要缺口**
   - `ffi_gen.go` P-09 注入只覆盖 `void/Int/Int32/Int64/Bool/String/handle/Bytes`；
     `Text/layout/数组/Float/Char/UInt` 等包装已支持但调用点未接。
   - 错误码非零在调用点 `exit(134)`，未映射为本地 `Result`（S7 §7.1/§7.2）。
   - `.transfer` 句柄包装要 `xrt_handle**`，调用点却传 `xrt_handle*`；`Bytes` transfer/reclaim 未实现。
   - `EmitTrampoline` 无调用方；`.xfb` 无回调声明语法。
   - `@unsafe` 只校验文本/`bindings/` 路径，未接 S8 `link.unsafe`。
   - 无实际 `@longRunning` 入口；codegen 未路由到 `xrt_companion_submit/wait`。
   - `xrt.h` 仍是候选冻结；`xrt_runtime_init` 未由生成代码调用；弱表无 bindings-only 构建检查。
   - `Bool` 出参非 0/1 直接 fatal，与 S7 §3.2“非 0 归一为 1”不一致。

3. **验收矩阵现状**：FFI-01/03 可维持 PASS；FFI-02/04/05/06/07 仍部分。
   台账 `XNull一致性用例台账-v1.0.0.md:103-109` 与此一致。

## 卡拆分（详见盘点文档）

S7-01 调用点编组扩展 → S7-02 错误码→Result → S7-03 trampoline 集成 →
S7-04 `@unsafe` 门禁 → S7-05 ABI v1 转正 → S7-06 长阻塞伴生路由 → S7-07 矩阵收口。
