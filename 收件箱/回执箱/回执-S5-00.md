## 冻结面

1. **对象模型**：`xrt_task` / `xrt_task_group` / `xrt_context` / `xrt_cancel_token` /
   `xrt_channel` / `xrt_mutex` / `xrt_atomic_*`；句柄 ARC，任务 env 为 GC 根。
2. **Closure/Result ABI**：`xrt_task_body(env, ctx, out)` + `xrt_task_result{ok,value,kind,error}`；
   业务 Err 原样交付，取消/超时用 S4 `xrt_error_kind`。
3. **Task/Group**：`group_new/spawn/cancel/close`、`join/join_deadline`；spawn 唯一创建路径；
   close = 取消 + 等待；重复 join/close = fatal。
4. **Context**：`background/child/with_deadline/check_cancel/cancel/token`；
   协作式取消；deadline 单调毫秒；`xrt_clock_mono_ms` 新 ABI。
5. **Channel/Mutex/Atomic**：有界 Channel（send 消费 +1 / receive 取得 +1 / close 终态）、
   作用域 `with_lock`、seq_cst 原子；元素 ops 负责引用持有。
6. **状态域**：0 成功、ErrorKind 错误面、`XRT_STATUS_CLOSED=100` 通道终态；合同错误 fatal。

## 与 S3/S4 边界

- S3：spawn 登记 env task root、终结注销；挂起前/恢复后 `xrt_safepoint`；栈根沿用 S3-02；
  队列元素由 ops/根持有；多线程化前置为 S3-06（原子弱表/屏障）。
- S4：复用 `xrt_error_kind`（Timeout=6/Cancelled=7），不新增枚举；禁止降级为 Internal；
  fatal 沿用 S4-06 单行/无堆诊断。
