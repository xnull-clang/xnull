# 回执：S6-09（E5 net runtime）

- 执行位：运行时线 E5
- 分支：`pod/e5-runtime`（按 ADR-010 未写 main）
- 结论：**完成运行时面**——socket plain/Async（可取消）+ net.http 最小 C/binding；
  close 合同与错误码映射落地
- 证据：`evidence/S6-09/`；接力棒 `handoff/S6-09-E5.md`

## 落地

- `rt_std_net.c`：
  - socket `connect/send/recv/close` plain；
  - `connect_async/send_async/recv_async`（Context 首参；poll 5ms + 取消 → code=3）；
  - HTTP `request/request_async` + `status/body/body_text/response_close`（HTTP/1.1，Connection: close）。
  - 错误码：0 ok / 1 InvalidArgument / 2 Io / 3 Cancelled / 4 Timeout / 5 Unavailable。
- `bindings/xdk/net.xfb`：Socket/HttpResponse 句柄 + 8 个 plain 入口 + errorMap；
  Async 走 codegen 内建发射。
- `runtimeCSources`/`build_test`/FFI 源清单/阻塞分类表同步。
- 顺手解除 main 合并残留的 `findManifestRoot` 重复声明（构建阻塞）。

## 先红/后绿

- 红：基线无 net 运行时，`test_net.c` 链接失败（`red.log`）。
- 绿：`build_rt.sh` exit 0（`net tests passed ...`）；FFI 绑定/清单测试 PASS；
  全量 codegen PASS；cli PASS；vet exit 0。

## 边界

- `xdk.net.http` 的 XNull 包装/`Context`/`Result` 发射属 E4/E2；本卡交付 C + `.xfb`。
- Async I/O 为 poll 轮询（可取消，但占当前载体）；调度器挂起式 I/O 未实现。
- HTTP 最小面只支持 HTTP/1.1 + `Connection: close`；无 TLS/chunked/重定向。
