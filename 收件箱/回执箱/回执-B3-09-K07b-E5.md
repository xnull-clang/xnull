# 回执：B3-09 K-07 双路径回归

- 执行位：运行时线 E5
- 分支：`pod/e5-runtime`
- 范围：仅新增 `tests/b3/k07_readfile.x`、`tests/b3/k07-readfile.sh`
- 未改：runtime、Go codegen、xnullc.x、绑定

## 交付

1. `tests/b3/k07_readfile.x`
   - `static Int main(String[] args)`，从 `args[0]` 取路径；
   - `xdk.sys.readFileText(path)` 读取，`Bytes.fromString` 后手工转十六进制；
   - 输出 `len=<字节数> head=<前 64 字节 hex>`（不足 64 字节取全部）。
2. `tests/b3/k07-readfile.sh`
   - 生成 2 MiB 确定性 ASCII 文本（2097152 字节）；
   - 临时工程内复制被测源与 `bindings/xdk/sys.xfb`（入口目录即 FFI 绑定根）；
   - 分别执行 `xnull run --interp` 与 `xnull run`（Go 编译 C 产物）；
   - 断言两路 stdout 一致，且等于独立期望值（`wc -c` + `od` 取前 64 字节）；
   - 缺失文件分别跑两路：退出码必须非 0，stderr 必须同时包含 `readFileText` 与路径。

- `go build ./cmd/xnull` 正常；解释路径与编译路径均使用同一份 `k07_readfile.x`。
- 缺失文件信息示例：
  - interp：`xnull: readFileText: 无法读取文件 "<path>"：open <path>: no such file or directory`
  - compile：`fatal: readFileText: 无法读取文件 <path>`（exit 134）
