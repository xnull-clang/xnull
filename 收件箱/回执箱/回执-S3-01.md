## 结论

T[] / List / Map / Set 已改为 GC 对象（分配头 + 长度 + 元素区），元素扫描与释放按元素种类分流；容器字段可作为 GC 引用持有并进入类扫描。

**先红（4/4）**
- 分配种类：无 `rt_gc_new`
- GC 元素：`List<Node>` 被拒绝
- 容器字段：类 scan 未访问
- clear：未立即释放 ARC 元素

**后绿**
- `TestS3_01*` 4 例 PASS；`go test ./...` 全绿；运行时六套件 exit 0。
- 冒烟：List<Int> 求和/长度、Set 去重、Map 字面量/getOr、List<String>、容器字段 push/get、List<GC Node> 退出回收。

## 实现要点

- 结构：`{rt_header hdr; len; cap; e *data}` / Set `{hdr; arr *a}` / Map `{hdr; len; cap; k *keys; v *vals}`。
- 描述符：`deinit` 释放 ARC 元素 + 元素区；`scan` 遍历引用元素；纯值元素 `scan=NULL`。
- 类型/调用：全部改指针（含入口 `String[] args`、for-in、split、下标、成员调用）。
- 元素：ARC 引用 retain/release；GC 引用只扫描；clear/remove 立即释放 ARC。
- 容器字段：scan 访问、deinit 不 release、赋值直接支持。

## 边界/转出

- 中途收集与局部容器根 → S3-02。
- 嵌套容器、struct 元素容器未支持（mangle 限制）。
- 容器改为引用语义（符合 §10；旧拷贝语义不再成立）。
