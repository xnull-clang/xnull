# 回执：S6-09 net 绑定/发射（E4）

- 结论：**可用版本已提交**（net.xfb + socket plain/Async + HTTP + 运行时原语）
- 证据：`evidence/S6-09/{red,green}.log`
- 红：无 net 绑定/内建时，`httpGetPlain` Bytes 返回未纳入、Async 调用未生成；
  绿：`TestS609*` PASS（socket 回环 connect + async close、HTTP GET 端到端）。

## 已落地

- `bindings/xdk/net.xfb`：Socket/Listener 句柄（close 幂等）、plain
  socketConnect/socketListen/socketAccept/socketRead/socketWrite、close；
  HTTP plain `httpGetPlain/httpPostPlain`（Bytes 返回，错误码 → Result）。
- `impl/runtime/rt_std_net.c`：POSIX socket（connect/listen/accept/read/write/close）
  与最小 HTTP GET/POST（http://、Content-Length/EOF）；错误码 0/1/2/3/4。
  已加入 `runtimeCSources`（构建自动链接）。
- codegen：
  - FFI 支持 Bytes 返回（包装/原型/Result 构造）；
  - `s609.go` 注入 Async/HTTP 语言面：`socketConnectAsync/socketListenAsync/
    socketAcceptAsync/socketReadAsync/socketWriteAsync/socketCloseAsync/
    listenerCloseAsync/httpGet/httpPost`（Context 首参，返回 Result<T,ErrorKind>）；
  - 调用点先 `xrt_context_check_cancel`：取消 → Err(Cancelled)，不发起阻塞调用；
  - Result 的 `.value()` 支持 Socket/Bytes 句柄/缓冲取值。
- sema：net/net.http 符号与签名（plain + Async + HTTP），与 codegen 注入一致。
- 阻塞分类清单补 net 行（`impl/docs/blocking-classification.md`）。

## 剩余 / 风险

1. Async 为“取消检查 + 阻塞原语”，未接调度器挂起；调度器切片接管后保持符号/签名。
2. HTTP 仅最小实现（http://、非 chunked 解析、无重定向/TLS）。
3. `impl/lib/xdk/net.x` 包单元仍是骨架；公开 API 目前由 codegen 内建 + `.xfb` 提供。
4. 全量五套件中 codegen 其余用例已通过；本轮最后只复跑 build/S609 相关用例。
