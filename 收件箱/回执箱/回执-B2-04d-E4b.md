# 回执：B2-04d-E4b 最小复现（E4）

- 结论：定位并修复一个 GC 根缺口；仍有一个未定位的 GC 临时根缺口，
  按指令停止继续消耗。
- 证据：`evidence/B2-04d/min-repro/`（r1–r5 + RESULTS.md）、`native-diff.tsv`。

## 已定位根因（已修）

`xs.push(new Tok(...))`：`new` 生成的 GC 类对象在 `push` 可能触发的分配/GC
之前未登记为根。修复：容器元素/方法实参中的 `new`/类调用先落临时并
`xn_root_add`（GC 类），再传入。r5 修复后 30/30 稳定输出 148890。

同时已修（前一提交）：类方法接收者重复求值；嵌套块内 GC 局部重赋值的根丢失。

## 未定位（停止点）

关闭 safepoint 后二者 AST 与 Go 逐字节一致。说明仍有另一处表达式临时/Result
载荷的 GC 根缺口，最小化未完成。
