## 一、红 → 绿

| 能力 | 修前（红） | 修后（绿） |
|---|---|---|
| `env(String) -> String?` | `String 表达式 *xfront.Call 未支持` | 内建 `xn_env_lookup`（直绑 `xdkc_env_get`）；可空 null 比较按 `has` |
| `dumpTasks()` | 无发射 | 生成侧计数 `xn_task_live`（spawn++/join--）+ 单行 `tasks: live=N` |
| `diagnose(String)` | 依赖项目 `.xfb` 装载 | 内建 `xdkc_diagnose`（单行折叠由运行时保证） |
| `exit(Int)` | 未发射 | 内建 `xdkc_exit`；进程退出码原样，**defer 不执行** |
| `nowMono()/nowWall()` | 未发射 | 内建 `xdkc_now_mono_ms/now_wall_ms` |
| 绑定说明 | runtime.xfb 仅 4 项 | 注明 env/dumpTasks 因 Optional 不跨 FFI 而走 codegen 内建 |

## 二、实现要点

- **env**：`xn_env_lookup(rt_string*) -> xn_opt_s`；缺失 → `has=0`，存在 → 复制
  `rt_string_new`。`String? e = env("X")`、`e != null`、`print(e)` 走既有可空路径。
  `env` 不经 `.xfb`：Optional 被 BOUND-02 禁止跨 FFI；绑定以生成前置原型呈现。
- **dumpTasks**：`xn_task_live` 由生成代码维护（spawn 成功 +1、join 成功 -1），
  `xn_dump_tasks()` 用 64B 栈缓冲 + `xdkc_diagnose` 输出单行；非承诺诊断面。
- **6 签名发射面**：`diagnose/exit/nowMono/nowWall/env/dumpTasks` 均可在无项目
  `.xfb` 时直接编译；`.xfb` 原有 4 项保留给 FFI 合同/包装路径。
- **exit 不执行 defer**：编译产物 `xdkc_exit`（`_Exit`）→ 退出码原样、defer 分支
  不可达；`TestS6_02ExitSkipsDefer` 断言 stdout 无 `defer-ran`、退出码 7。
- **任务计数联动**：S5-04 spawn/join 发射点补 `xn_task_live` 更新，供 dumpTasks
  观测（spawn 后 live=1，join 后 live=0）。

## 三、边界

- `dumpTasks` 为生成侧可见计数（codegen 经手的 spawn/join），不含运行时内部
  队列/载体线程细节；S6 §4.4 明确其为“实现侧诊断、非承诺、不入 ABI”。
- 解释器（`--interp`）的 XDK 桥接仍缺（S6盘点 P1-3）；本卡做的是编译路径。
- env 快照语义由 E5 runtime `xdkc_env_get` 保证（不可变/首批快照）；codegen 只做
  Optional 映射。
- 运行时 `dumpTasks` 专用 API 未新增；若 E5 后续提供 `xrt_task_dump`，可替换
  `xn_dump_tasks` 的数据源而不改调用点。
