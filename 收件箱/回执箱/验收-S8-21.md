```bash
# 合并门禁：默认 0/4 跑完全部 4 片并聚合；--merge 持有 handoff/merge.lock 且并发不低于 4
XNULL_FRONTEND=go xnull dev test --merge --parallel 4

# 指定包（本次验收口径）
XNULL_FRONTEND=go xnull dev test --merge --parallel 4 ./internal/codegen

# 显式全分片（与默认 0/4 等价）
XNULL_FRONTEND=go xnull dev test --shard 0/4 --parallel 4 ./internal/codegen

# 包级并发
XNULL_FRONTEND=go go test -p 4 ./...

# B2 差分批处理
bash tests/b2/batch.sh --parallel 4
```

门禁语义：`--shard 0/n` 跑完全部 n 片并聚合，任一片失败即返回非 0（`runJobs` 置 `failed`）。
