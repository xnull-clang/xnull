## 2. 保留项

| 项 | 入口 | 说明 |
|---|---|---|
| 开发期快速测试 | `xnull dev test --fast [包...]` | 只跑指定包或相对 main 变更的包 |
| 稳定哈希分片 | `xnull dev test --shard k/n --parallel N` | FNV-1a 按测试名取模，切片确定性；`--shard 0/n` 跑完全部片并聚合，任一片红即整体红 |
| 并发分片 | `--parallel N` | 每个分片一个独立 `go test` 进程，汇总各自 PASS/FAIL/耗时 |
| 串行标记 | `handoff/serial-tests.txt` | 并发/端口/全局状态用例显式登记，切片时摘出、最后单独串行跑一次 |
| B2 差分批处理 | `bash tests/b2/batch.sh --parallel 4` | L1 语料分片并行，每进程独立 `B2_TMP`；实测 PASS=101 FAIL=0 |
| 合并锁 | `xnull dev test --merge ...` | 持有 `handoff/merge.lock`（`O_EXCL`），同一时刻只允许一套全量；退出自动释放 |

## 3. 合并门禁命令

```bash
# 推荐（等价全分片）：默认 0/4 跑完全部 4 片并聚合，任一片红即整体红
XNULL_FRONTEND=go xnull dev test --merge --parallel 4

# 指定包时
XNULL_FRONTEND=go xnull dev test --merge --parallel 4 ./internal/codegen
```

`--merge` 不写 `--shard` 时自动取 `0/4` 且并发抬到 4（`gatePlan`，有单测 `TestGatePlanAllShards` 覆盖）。
已实测 `--merge --parallel 4` 正常加锁/释放（`handoff/merge.lock` 退出后不残留）。
