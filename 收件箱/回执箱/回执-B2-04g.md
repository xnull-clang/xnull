# 回执：B2-04g 可取消的外部解释器 runner

- **状态**：`DONE`
- **提交**：`046b128e0b97`（`pod/e2-sema`）
- **测试硬规则**：收到-切片并发；本轮包级 `go test -p 4`，门禁实测使用 `xnull dev test --parallel 4`。

## 实现

1. 新增 `impl/cmd/xnselfhost`：加载 `xparser.x`/`xlex.x` 后用 `interp.Run` 执行，
   stdout/stderr 与 `xnull run --interp` 一致。
2. `frontbridge` 自动构建并缓存 helper（`go build ./cmd/xnselfhost`，缓存键含 helper 源码 + `go.mod` + 版本），
   用 `exec.CommandContext` 调用，默认 **5s** 硬超时（`XNULL_SELFHOST_TIMEOUT`）。
3. 超时一律回退 Go 并记录 **B2-002**（`frontbridge.LastIssue()`）；显式 `xnull` 的其它失败仍报 B2-001。
4. 不再依赖进程内 runner；原生 parser 仅显式 `XNULL_NATIVE_XPARSER` 可选。
5. 默认模式走 xnull 管线（helper + 磁盘缓存）；helper 不可用/失败时回退 Go。
