# 回执：S3-09 / P1-4 类标量字段 8 字节槽

- 卡片：S3-09（P1-4：标量字段未占 8 字节槽，S3 §2 / S2 §3.6）
- 提交：`e2040d6`（仅 pod/e4-codegen，未 merge main）
- 顺序：先红后绿。

## 一、红 → 绿

| 用例 | 修前（红） | 修后（绿） |
|---|---|---|
| `class C { Int32 a; Int64 b; Bool flag; }` | `int32_t a; int64_t b; int flag;`（4 字节窄字段） | `int64_t a; int64_t b; int64_t flag;`（统一 8 字节槽） |
| 运行 `c.a=2147483647; c.b=9223372036854775807; c.flag=true` | — | `2147483647 / 9223372036854775807 / true` |
| Int32 语义宽度 | — | 读取转 `int32_t`、写入先截断再存槽；Int64 不变 |
| Bool 语义 | — | 读取转 `int`，print 仍走 Bool 分流 |

回归：`go test ./internal/codegen/... ./internal/cli/ ./internal/interp/ ./internal/sema/ -count=1` 全绿。

## 二、实现要点

- `classField` 增 `semC`（声明语义 C 类型）；存储 `ctype` 经 `slotCType` 加宽：
  `int32_t` / `int`（Bool）→ `int64_t`，`int64_t`/指针不变。
- 作用域：class、数据枚举、单例、泛型类实例字段；主构造器隐式字段同样加宽。
- 字段读：`fieldReadExpr` 按 `semC` 转换（Int32→int32_t、Bool→int）；写：
  `fieldStoreExpr` 先截断到语义宽度再存入 8 字节槽。字段初始化/赋值/类字段读全路径一致。
- 字段顺序、继承前置字段、vtable 指针槽位置不变；全部字段 8 字节对齐。

## 三、ABI 影响评估与处理

- 类对象载荷 `rt_type.payload_size` 变化：窄标量字段 4→8 字节，字段偏移
  整体按 8 字节槽推进；同一程序/版本/选项下确定性不变。
- 生成代码内部 ABI：类对象只经指针传递，字段访问由 codegen 统一生成；
  无外部稳定 ABI 承诺，FFI 不按类内存布局传递（S3 §19 布局兼容需逐类型验证）。
- 继承：父类字段在子类前置，槽宽一致后偏移仍连续；方法/构造器代码同步重生成。
- 容器：类元素为指针槽（8 字节），不受影响；struct 值布局不在本卡范围
  （§3.6 的 struct 8 字节槽另列）。
- 顶层/静态字段暂未纳入（本卡只类字段）；后续卡可按同一 `slotCType` 规则处理。
