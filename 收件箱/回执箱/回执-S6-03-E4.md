## 二、阻塞项（如实报告，未假实现）

1. **Process 句柄**：E5 runtime 目前只有 `xdkc_proc_status`（同步退出码），
   没有可包装的 `xrt_handle`（spawn/wait/close）。`Process { close = ... }`
   需要 E5 先提供进程句柄原语；本卡不伪造。
2. **plain/*Async 双形态（Context 首参）**：`.xfb` 无法表达 `Context` / `Result` /
   `Optional`（BOUND-02 禁止 Result/Optional 跨 FFI）；异步形态需由 **S6-01（E2）**
   先落语言面签名，再由 E4 以 codegen 内建发射（挂起点检查 `xrt_context_check_cancel`
   + 可取消返回），并等待 E5 异步执行器。当前 main 无 S6-01，无法先红后绿。
3. 依赖：S6-03 卡片依赖 S6-01（E2）。本卡先把不依赖签名表的 plain 原语与句柄
   合同用例交付，其余在 S6-01 合并后补。
