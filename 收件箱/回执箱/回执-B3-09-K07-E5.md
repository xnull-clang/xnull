# 回执：B3-09 K-07 文件输入通道（runtime/interp）

- 执行位：运行时线 E5
- 分支：`pod/e5-runtime`
- 范围：`impl/lib/xdk/sys.x`、`bindings/xdk/sys.xfb`、`impl/runtime/rt_std_sys.c`、
  `impl/runtime/test_std.c`、`impl/internal/interp/**`、`impl/internal/sema/**`、
  `impl/internal/codegen/ffi/*_test.go`、`impl/docs/blocking-classification.md`、`tests` 未改
- 未改：`impl/lib/b3/xnullc.x`、Go codegen 发射面

## 交付

1. **C 运行时**（`rt_std_sys.c`）
   - `xdkc_read_file_text` 保留原合同：成功返回复用缓冲，失败返回 NULL，不 panic。
   - 新增同线程错误旁路 `xdkc_read_file_text_error()`（0 成功 / 2 打开或读取失败）。
   - 读取上限 64 MiB（K-07 要求 ≥16 MiB）；`xdkc_read_file_text_code` 与 C 测试共用。
2. **绑定**（`bindings/xdk/sys.xfb`）
   - 原始入口 `readFileTextRaw(String) -> String`（`xdkc_read_file_text`）。
   - `readFileTextError() -> Int32`（`xdkc_read_file_text_error`）。
   - 不用 `@errorCode`：String 载荷从 Result 取出的代码生成面尚未落地，
     改用错误旁路；调用未加 `@longRunning`，不走 companion 路由，错误不跨线程。
3. **源码层 API**（`impl/lib/xdk/sys.x`）
   - `String readFileText(String path)`：读原始入口后检查错误码，非 0 即 `throw`，
     明确点名函数与路径，不返回空串。
4. **解释器桥**（`impl/internal/interp/sys_xdk.go`）
   - `readFileText` 同名内建优先于源码包装：直接读文件，失败抛
     `readFileText: 无法读取文件 "<path>"：<原因>`，超 64 MiB / 非 UTF-8 同样报错。
5. **签名/文档**
   - `xdksig.go` 登记 `readFileText`（用户面）、`readFileTextRaw`、`readFileTextError`。
   - `blocking-classification.md` 同步原始入口 cName 与新增错误读取入口。

## 测试（先红后绿）

- 红（实现前）：
  - `go test ./internal/interp -run TestS8K07` → `未定义的函数：readFileText`
  - `go test ./internal/cli -run TestS8K07` → 同上
  - C 侧链接 → `Undefined symbols: _xdkc_read_file_text_error`
  - 日志：`evidence/B3-09-K07/red-*.log`
- 绿：
  - `go test ./internal/interp -run TestS8K07` → PASS（1 MiB 长度=1048576；缺失文件显式错误）
  - `go test ./internal/cli -run TestS8K07` → PASS（`xnull run --interp` 同口径）
  - `sh impl/runtime/build_rt.sh` → EXIT=0（含 `std 测试通过`，1 MiB 读 + 错误码断言）
  - `go test -p 4 ./internal/interp ./internal/sema ./internal/codegen ./internal/codegen/ffi` → 全绿
  - 日志：`evidence/B3-09-K07/green-*.log`
- 编译路径人工验证：`xnull run`（非 --interp）读 1 MiB 输出 `1048576`；
  缺失文件输出 `fatal: readFileText: 无法读取文件 <path>`，退出 134。

## 说明

- 绑定名由 `readFileText` 改为 `readFileTextRaw`，避免与 `xdk.sys` 源码层包装重名
  （P-09 条件 1）；用户面 API 仍是 `readFileText`。
- 既有 B0-06 绑定测试同步改为验证原始入口，仍覆盖“成功读取 + 缺失→NULL”合同。
