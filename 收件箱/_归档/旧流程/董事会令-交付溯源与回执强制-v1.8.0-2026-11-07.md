## 第 0 条　问题定性

**这不是“忘了写”，是交付链断了。**

- 会话里说“DONE”，收件箱没有文件 → 无法溯源；
- 文件写在各自 worktree，根目录看不到 → 董事会收不到；
- 没有回执 → QA 无法签、台账无法改、里程碑无法计。

**董事会责任**：派工时只写了“写回执”，没规定唯一路径、没规定字段、没做强制校验。

---

## 第 1 条　唯一回执路径（从本件起）

```
收件箱/回执箱/<司>/<卡片ID>.md
```

示例：

```
收件箱/回执箱/CEO1/回执-M1-ERR-01.md
收件箱/回执箱/CEO2/回执-M1-BLD-01.md
收件箱/回执箱/CEO3/验收-M1-DET-01.md
```

- **绝对路径**：`/Users/vjs/Desktop/XNull-Lang/收件箱/回执箱/...`
- 不放在 worktree 里，不依赖分支合并；
- 一个卡片一个文件，不合并、不追加到别人的文件。

---

## 第 2 条　回执必填字段（缺一即无效）

| 字段 | 要求 |
|---|---|
| `卡片ID` | 正式 ID，如 `M1-ERR-01` |
| `角色/会话` | 角色名 + `ses_…` |
| `结论` | `DONE / BLOCKED / FAIL`（不得写“基本完成”） |
| `改动` | 文件清单 + 一句话 |
| `验证` | 可复制命令 + 实际结果 |
| `sha` | commit sha（无 commit 写 `none`） |
| `证据` | `evidence/…` 路径 |
| `未测/风险` | 至少一行；没有就写“无” |
| `下一步` | 若未 DONE，写清谁做什么 |

**没有回执 = 本卡未完成。** 聊天记录、会话回复不算交付。

---

## 第 3 条　溯源链（唯一口径）

```
任务卡ID
  → 会话ID
  → 回执（收件箱/回执箱）
  → commit sha
  → evidence/<卡片ID>/ 七件套
  → QA 验收文件（收件箱/回执箱/<司>/验收-<卡片ID>.md）
  → 台账行状态
  → 门禁结论
```

链上任一环缺失：**该卡不计入里程碑**，主责记 `ERR-007（无回执交付）`。

---

## 第 4 条　强制校验

1. 每个任务卡最后一行必须是：`回执路径：收件箱/回执箱/<司>/<卡片ID>.md`。
2. 会话结束前必须写该文件；没写就结束 = 未完成。
3. 董事会每 30 分钟审计一次：
   - 有 commit、无回执 → 自动催交，10 分钟内不补 → 本卡降为未完成；
   - 回执缺字段 → 打回重写；
   - 同一角色 2 次无回执 → WIP 降为 0，只做补交。
4. QA 只认回执箱 + evidence，不认聊天。
5. CEO1 门禁只认 QA 文件 + 回执箱，不认口头汇报。
