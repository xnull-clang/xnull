## 四、证据审计规则（2 小时内出结论）

1. **触发**：任一锚点主责在 `收件箱/` 报完成，或 main 出现该锚点 commit，即开始计时。
2. **时限**：**2 小时**内出「齐全 / 缺项」结论，写入本文件 §五 与 `M1缺证清单`。
3. **结论只有两值**：`齐全`（七件套 + L1 签署全）或 `缺项`（逐项列出文件/签名）。
4. **缺项处理**：退回该司 QA/主责；**不改门禁结论**、不代替 L1 签字、不删证据。
