# 董事会令：董事会不碰代码 v1.0.0

> **签发：董事会　2026-11-07 12:45　性质：治理边界令，立即执行**
> **触发：用户裁决「怎么董事会判决的都开始写代码、修改 Bug 了？」**
> **本件冻结，不得修改；修订另发 v1.0.1。**

---

## 第 1 条　定性

董事会刚才做了四件不属于自己的事：

1. 直接 `git merge` 分支；
2. 直接解冲突；
3. 直接 build/跑修复验证；
4. 直接改代码修 bug。

**这是越界，不是勤奋。** 董事会一旦下场写代码，就失去独立验收的资格。

---

## 第 2 条　董事会只做四件事

| 允许 | 禁止 |
|---|---|
| 发任务卡、派工、换人 | 写/改生产代码 |
| 读回执、看 evidence、只读抽查 | 解 git 冲突 |
| 签 L4、发判决、改标准 | 修 bug、改测试 |
| 升级阻塞、改组 | 代跑集成、代合分支 |

**唯一例外**：无。执行角色不可用时，董事会只能指定另一个执行角色接手，不能自己上。

---

## 第 3 条　集成与合并归谁

| 动作 | 主责 | 会签 |
|---|---|---|
| 分支 merge main、解冲突 | **文件所有者** | 该司 CTO |
| 合并队列、顺序、阻塞 | **CEO2** | CEO1 |
| 合并后全量测试 | **QA（该司）** | CEO1 |
| main 快进/合并执行 | **COO**（仓库操作） | CEO2 |
| 门禁 | CEO1 | 董事会（L4） |

董事会只接收 `SYNCED <sha>` 回执与 QA 结论。

---

## 第 4 条　已发生的越界操作

| 操作 | 处置 |
|---|---|
| 董事会代合 e2、c2-rd1、c3-rd1、c3-rd2 入 main | 标记“代操作”；CEO2 复核，QA 重跑；不合格则回退 |
| 董事会代跑 B0-06/B0-05 验证 | 只作为只读抽查；正式结论由 QA1 出 |
| 3 个冲突分支未合 | 退回所有者，CEO2 排 queue |

---

## 第 5 条　一句话

**董事会是裁判，不是球员；再下场写一行代码，自罚一次失职。**
