### 用例 2 自造源码要点

```text
main.xn      import lib.alpha; import lib.beta
lib/alpha.xn class A { Int sumWith(B other) { ... } }   // 引用 B
lib/beta.xn  class B { Int adopt(A a) { ... } }          // 先被加载，引用 A
```

加载顺序（依赖在前）：`beta(B) → alpha(A) → main`。B 的定义早于 A，参数类型 A 只能靠前向声明；基线 ad70f19 在 cc 阶段报 `unknown type name 'xn_Cls_A'`，overlay E4 后编译通过且输出与解释一致。期望值 `12`（7+5）与 `5`（adopt 返回 self.v）由 QA1 手算，未抄实现输出。

## 三、附加发现（不计入 2/2）

`stress/` 变体：B 先定义，方法体 `return self.v * a.v` 访问 A 的字段。overlay E4 后仍失败：

```text
error: incomplete definition of type 'xn_Cls_A' (aka 'struct xn_Cls_A')
```

判断：E4 的前向声明覆盖“指针级使用”（参数/字段/原型），但方法体内解引用后定义类仍需完整定义；若要支持任意互相引用，需要类定义拓扑排序或拆分声明/实现。建议单独登记，不阻塞本卡 2/2。
