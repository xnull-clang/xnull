## 0. 结论先行

1. 二司运行时域在 101 锚点中占 **27 条**：S3 11（MEM-03—13）、S5 9（TASK-01—04 / SYNC-01—03 / SCHED-01 / BLOCK-01）、S7 7（FFI-01—07）。台账现状：**PASS 2（FFI-01、FFI-03）、部分 5（FFI-02/04/05/06/07）、其余 20 条未实现**。
2. 本文件给出 **25 条 PM 验收条款**（S3 10、S5 7、S7 8），每条形如“源条款 → 断言级验收 → 锚点 → 现状 → 边界”。
3. **S3/S5/S7 当前不具备语句级条款 ID**，本文件的 `PM-S3-xx` 是定位 ID，**不能**当台账锚点用；因此在 S0-14 条款 ID 生成器落地前，**任何“条款追溯 100%”的签署都是伪精确**（见 §5 D-1）。
4. **S5 §10 的 12 项验收只进了 9 个锚点**：`CANCEL-01`/`CANCEL-02`/`TIMEOUT-01` 未进入 101 表（台账 S4 另有同名 CANCEL-01/02，内容不同）。S5 现在**不能宣称验收矩阵全覆盖**（见 §5 D-2）。
5. 运行时域的技术债不是“缺文档”，是**取证能力缺失**：ASan 本机 SIGILL、弱表 UAF 只能静态判定、`xrt_safepoint` 不触发 GC、并发子切片未接。MEM-03/04/08/09 与 SYNC-03 的“并发安全”在现有工具链下**无法给出可复算证据**（见 §5 D-6）。

## 4. 域边界（谁定什么，PM 不越界）

| 事项 | 归属 | PM 的位置 |
|---|---|---|
| 内存/任务/FFI 的**运行时语义与验收口径** | 本文件（二司 PM） | 主责 |
| 源码可观察语义（策略判定表、逃逸分类、布局、混合图、`deinit` 顺序、弱引用规则） | S2（一司） | **冲突以 S2 为准**（S3 §0.2），PM 只做实现侧补充 |
| `Result`/`try`/`defer`/`errdefer`/`throw` 语法与传播 | S1（一司） | 只引用，不重定义 |
| `ErrorKind` 集合、错误观测、取消/超时错误面 | S4（一司） | S7 只做映射，不改 kind 定义（S7 §1.3） |
| `xdk.*` 包名、类型名、函数签名、阻塞分类清单的**发布形态** | S6（三司） | S5 §1.3、S7 §0 明确“名称以 S6 为准”；PM 验语义一致，不代写 API |
