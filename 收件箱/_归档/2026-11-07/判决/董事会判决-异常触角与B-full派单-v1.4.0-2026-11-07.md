## 第 4 条　语言路线裁决：B-full 立即执行

### 4.1 路线（不变）

| 层 | 语言 | 边界 |
|---|---|---|
| 编译器 + 工具链前端 | **Go** | 唯一实现语言 |
| 运行时 | **C** | 唯一实现语言 |
| 仓库维护脚本 | Python → **迁走后归零** | 过渡期仅 `check_specs`、`gen_ledger`、`gen_resources` 三个 |

### 4.2 B-full 内容

把三项 Python 工具统一改为 Go 子命令：

```
xnull dev check     # 规范守门（原 check_specs.py）
xnull dev ledger    # 台账生成（原 gen_ledger.py）
xnull dev res       # 资源表生成（原 gen_resources.py）
```

然后：

1. `impl/runtime/build_rt.sh` 改为调用 `xnull dev res`（这是唯一进入构建的 dev 子命令）；
2. 删除 `impl/tools/*.py`；
3. 更新 `impl/README.md`、`impl/docs/**` 与台账头部说明；
4. 开发工具链只依赖 **Go + C**，Python 归零。

### 4.3 不可越过的边界

- `xnull dev res` 是构建期工具，**不得成为产品运行时依赖**；运行时产物不得链接 Go 或携带 Go 运行时。
- 不得为了“让测试过”改台账状态、改规范、改示例期望。
- 不得把 Python 保留为“可选回退”；迁移完成后 Python 必须为 0。
