## 第 0 条　新里程碑

**M6 = 自举版（Self-hosted XNull）。** 不是“下一个 commit”，是五道门 B0–B4 全部通过。

Go 1.4 → 1.5 的映射：

| Go 历史 | XNull 现在 |
|---|---|
| C 写 Go 1.4 编译器 | **Go 写当前 `xnullc`**（借力） |
| 用 C 版编译器编译 Go 版编译器 | 用 Go 版编译 **XNull 写的 `xnullc`**（xn-s1） |
| Go 版编译器自编译 | xn-s1 编译 xn-s2 |
| 删除 C 版 | **B4 后删除 Go 版** |
| 此后每版由上一版 Go 编译 | 此后每版由上一版 XNull 编译 |

**自举对象**：编译器前端 + 代码生成器（`xnullc`）。
**不自举**：C 运行时、系统 `cc`、平台 ABI —— 长期保留（死命令 1.1.3）。

## 第 4 条　不可协商条款（引自死命令，不得降级）

1. **DET-01 从 B1 起对自举版生效**：map 参与输出必须排序；自举版要有独立确定性用例。
2. **C 运行时不动**：同一套 `rt.h`、`rt_gc.h`、`xrt.h`，不得另立运行时或 ABI。
3. **单一实现**：B4 通过即删除 Go 版编译器，不得长期双实现。
4. **不得引入第三方语言**：Rust/Zig 等不用于替换 Go 版。
5. **不得曲解**：B2 未开工不得对外称“已自举”；自举不是性能优化。
