## 二、关键语义修复（真缺陷，非新增功能）

**while 条件含字符串临时时被提升到循环外**：条件求值产生的前置语句（如 `self.at()` 的临时串）原先被搬到 `while` 之前，条件只算一次 → 死循环/条件不更新。修复为：

```c
while (1) {
    <条件求值前置语句>
    if (!(<cond>)) { break; }
    <循环体>
}
```

每轮重新求值；`continue` 跳到顶部同样重新求值，语义等价 §6.4。

## 三、自举素材 #1：`examples/lexer-seed.xn`

XNull 实现的词法扫描器（类 + 字段 + 方法 + 嵌套 while/if-else 链 + 字符串拼接）：

```xn
class Scan {
    String src;  Int pos = 0;  Int ntoks = 0;
    Bool eof();  String at();  Bool isDigit(String c); ...
    void scan();  // 空格跳过 / 标识符 / 数字 / 符号 / 其他
}
```

对输入 `let total = 42 + x1;` 产出：

```
id:let
id:total
sym:=
num:42
sym:+
id:x1      ← 标识符续字符含数字
sym:;
7          ← token 数
20         ← 扫描终点
```

**验证**：编译路径与解释路径 **stdout 逐字节一致**，退出码双方 0。
