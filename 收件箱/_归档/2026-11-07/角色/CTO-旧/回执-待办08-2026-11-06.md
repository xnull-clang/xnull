## 四、示例与验证

`examples/multi/{main.xn, lib/shapes.xn, lib/text.xn}`：

```
$ xnull run --interp multi/main.xn > a   # [xnull] / 25 / [norm=25]
$ xnull build multi/main.xn -o bin && bin > b
$ diff a b                                # 无输出（逐字节一致），退出码双 0
$ xnull build main.xn -o d1 && build -o d2
$ diff d1.c d2.c                          # 无输出（C 产物确定性）
```
