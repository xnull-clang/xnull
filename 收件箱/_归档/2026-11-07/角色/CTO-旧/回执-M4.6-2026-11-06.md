## 二、验收锚点

| 锚点 | 证据 |
| --- | --- |
| `diagnose` 单行、无分配 | `test_std.c`：stderr 重定向后逐字节比对 `"line1 line2\n"` |
| `exit` 不执行 defer/atexit | `test_std.c`：子进程注册 atexit 后 `exit(7)`，退出码 7 且标记文件为空 |
| `nowMono` 单调、`nowWall` UTC 毫秒 | 连续调用不减；墙钟 > 1.7e12 |
| `env` 不可变快照 | 同名变量改值后再读仍为首次值；缺失变量返回 NULL/长度 0 |
| 严格解析 | `"4x"`→1、`""`→1、溢出→2；`parseFloat` 同款 |
| 编码转换 | `a😀b` UTF-8→UTF-16（4 单元）→UTF-8 往返一致；过短编码/代理区/目标不足 → -1 |
| 文件句柄合同 | 读满/读到尾/缺失文件 NULL/重复 close=0；经 FFI 包装路径同样成立（`xdk_test.go`） |
| 源码层可编译 | `xdk_seed_test.go`：ParseUnit + Analyze + EmitC 无诊断，生成含 3 个符号 |
