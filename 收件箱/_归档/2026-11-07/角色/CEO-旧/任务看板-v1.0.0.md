## 四、更新规则

| 项 | 约定 |
|---|---|
| **何时更新** | ① 每次派工、认领、交付、打回、过门后 ≤30 分钟；② 每日 18:00 全量核对一次；③ 阶段门后强制刷新；④ 会话新建 / 迁移 / 归档后即时同步。 |
| **谁来更新** | **CEO 是唯一维护人**（判决 v1.3.0：CEO 写入域含 `收件箱/**`）。主责角色不得直接改表，只提交回执与证据；CTO 提供评审结论；董事会维护台账。 |
| **冲突以谁为准** | ① 角色、会话 ID、卡号 → **会话台账**为准（台账原文：“本表是唯一权威；与看板冲突以本表为准”）；② 任务内容、依赖、验收 → **董事会任务执行报告 + 判决**为准；③ 完成与否 → **`evidence/` + 可复现命令**为准，回执文字不算；④ 缺陷状态 → **缺陷登记表**为准。 |
| **卡号口径** | 只允许 `S<阶段>-<序号>`。台账与本表出现同号不同义，立即停派该卡并升董事会。 |
| **版本方式** | 不覆盖。每次结构变更另发 `v1.0.x`，在「变更记录」列出增删行。 |
| **禁止** | 不得凭回执把卡置 `通过`；不得同一角色同时出现两张 `进行中`；不得私自新增角色行（扩编须董事会发判决）。 |
