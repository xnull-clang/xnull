## 0. 分层与判定

| 层 | 验什么 | 当前可执行性 |
|---|---|---|
| sema | 类型/签名/Context 首参/子包导入 | 可执行（`xnull check`） |
| interp | XNull 解释路径的 socket/http 行为 | `BLOCKED`（E5/E3 未接） |

## 2. 最小用例

### NET-01 plain socket

```x
// tests/s6/xdk09/net_plain.x
import xdk.net
import xdk.tasks
import xdk.errors

@tasks
static Int main() {
    Result<Listener, Error> bl = bind("127.0.0.1", 39107)
    if (bl.isErr()) { print("bind err"); return 1 }
    Listener l = bl.value()
    Context c = Context.background()
    TaskGroup g = TaskGroup.create(c)
    Task<Int> srv = g.spawn(() -> {
        Result<Socket, Error> ar = l.accept()
        if (ar.isErr()) {
            Result<Int, TaskError> bad = Ok(1)
            return bad
        }
        Socket s = ar.value()
        Bytes b = Bytes.fromString("....")
        Result<Int, Error> r = s.read(b)
        Result<Int, Error> w = s.write(Bytes.fromString("pong"))
        Result<void, Error> cl = s.close()
        Result<Int, TaskError> ok = Ok(0)
        return ok
    })

    Result<Socket, Error> cr = connect("127.0.0.1", 39107)
    if (cr.isErr()) { print("connect err"); return 2 }
    Socket sock = cr.value()
    Result<Int, Error> w = sock.write(Bytes.fromString("ping"))
    Bytes buf = Bytes.fromString("....")
    Result<Int, Error> n = sock.read(buf)
    print(n.value())
    Result<void, Error> cl = sock.close()
    Result<void, TaskError> gcl = g.close()
    print("plain ok")
    return 0
}
```

### NET-02 Async + 取消

```x
// tests/s6/xdk09/net_async_cancel.x
import xdk.net
import xdk.tasks
import xdk.runtime
import xdk.errors

@tasks
static Int main() {
    Context root = Context.background()
    Context deadline = root.withDeadline(nowMono() + 20)
    Result<Socket, Error> cr = connectAsync(deadline, "127.0.0.1", 39108)
    if (cr.isErr()) { print("connect err"); return 1 }
    Socket s = cr.value()
    Bytes buf = Bytes.fromString("....")
    Result<Int, Error> r = s.readAsync(deadline, buf)
    if (r.isErr()) {
        Error e = r.error()
        if (e.kind() == ErrorKind.Cancelled) { print("cancelled") }
        else { print("other") }
    } else {
        print("unexpected")
    }
    Result<void, Error> cl = s.close()
    return 0
}
```

期望：

```text
cancelled
```

> 服务端 fixture 在 39108 接受连接后延迟 200ms；客户端截止 20ms，`readAsync` 必须返回 `Cancelled`，不得返回 `Timeout`/`Io`。

### NET-05 错误映射

```x
// tests/s6/xdk09/net_errors.x
import xdk.net
import xdk.net.http
import xdk.errors

static String kind(Error e) {
    if (e.kind() == ErrorKind.Network) { return "network" }
    if (e.kind() == ErrorKind.InvalidArgument) { return "invalid" }
    if (e.kind() == ErrorKind.Cancelled) { return "cancelled" }
    if (e.kind() == ErrorKind.Io) { return "io" }
    return "other"
}

static Int main() {
    Result<Socket, Error> r = connect("127.0.0.1", 39110) // 无服务端
    if (r.isErr()) { print(kind(r.error())) }

    Result<Response, Error> b = get("not-a-url")
    if (b.isErr()) { print(kind(b.error())) }

    return 0
}
```

期望：

```text
network
invalid
```

> 连接拒绝 → `Network`；URL/地址非法 → `InvalidArgument`；取消 → `Cancelled`（NET-02）；未知原生码 → `Internal`，不得降级为 `Ok`。

## 3. 服务端 fixture

| fixture | 端口 | 行为 |
|---|---|---|
| `tests/s6/xdk09/fixtures/echo_server.c` | 39107 | accept 后读 4 字节，回写 `pong`，退出；供 NET-01/03 |
| `tests/s6/xdk09/fixtures/delay_server.c` | 39108 | accept 后 sleep 200ms，再回写 `late`；供 NET-02 |
| `tests/s6/xdk09/fixtures/http_server.c` | 39109 | 顺序处理 3 请求：`GET /hello` → `200` + `Content-Type: text/plain` + `hello`；`POST /echo` → `201` + 请求体；`GET /missing` → `404` + `not found`；供 NET-04 |
| 无服务端 | 39110 | 连接拒绝；供 NET-05 |

> 端口固定为 391xx；runner 启动前检查占用，冲突即失败并给出端口。不依赖外网。
