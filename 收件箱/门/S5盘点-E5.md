## 三、P0 缺口（S5 门阻断）

### P0-1 调度器与任务运行时整体缺失（§2/§3/§4）
- 现状：没有任务对象、队列、载体线程、取消/等待；`TaskGroup` 只是 sema 符号。
- 最小复现：
  ```x
  import xdk.tasks
  static Int main() {
      Context c = Context.background()
      return 0
  }
  ```
  `xnull check` 通过；`xnull build` 报 `codegen：类型 Context 未支持（M4.1 范围）`。
- 影响：TASK-01..04、附录 A 全部不可执行。
- 归属：E5（调度器/任务对象 C 运行时）+ E4/E2（语言类型与调用降级）。

### P0-2 取消/超时机制缺失（§5/§6）
- 现状：无 Context 令牌、无检查点、无定时器；S4 只落了错误面枚举。
- 最小复现：无 `checkCancel`/`withDeadline` 可调用；`joinDeadline` 无任务可 join。
- 影响：CANCEL-01/02、TIMEOUT-01；S4 的取消/超时契约无法验证。
- 归属：E5（机制）+ E2/E4（API 面）。

### P0-3 同步原语缺失（§7）
- 现状：Mutex/Channel/Atomic* 无运行时实现与 XDK 包装。
- 最小复现：`import xdk.sync` 通过检查，使用 `Mutex<Int>` 即 codegen 未支持。
- 影响：SYNC-01..03；跨任务共享无合法形态。
- 归属：E5（C 原语）+ E4/E2（数据携锁/类型检查）。

### P0-4 跨任务内存合同未接线（§2.1/§9、S3 §11）
- 现状：`xrt_task_root_bind/unbind` 只是 GC 根别名；无任务 env 生命周期、无挂起点发布点；
  弱表/GC 全局结构未并发化。
- 最小复现：无法创建任务；两线程直接调用运行时会在 `g_gc_list`/`g_roots`/弱表上竞争。
- 影响：TASK-03、S5 §9 门槛、S3-06/MEM-09（B3 回验）。
- 归属：E5（B3）。

### P0-5 `@tasks` 语义与任务 API 的可见性（§2.3）
- 现状：注解白名单认识 `@tasks`，但不校验块外调用，不做 external root 处理。
- 影响：BLOCK-01；错误使用无法被拒绝。
- 归属：E2（sema）+ E4（codegen 块边界）。

### P0-6 长阻塞 `.unaware` 的伴生执行器缺失（§2.2、S7 §7.3）
- 现状：`BlockingManifest` 有 `.unaware`/`longRunning` 与伴生入口校验；无执行器实现。
- 影响：SCHED-01 的运行半段；长阻塞会占死载体线程。
- 归属：E5（B3）。
