# S3-02 前置：GC 根审计（E2 sema 面）

- 依据：`ADR/ADR-007-S3定版裁决.md`；`收件箱/门/S3盘点-E5.md` P0-4
- 范围：只审计 GC 根来源与 codegen 登记缺口；不改 runtime/codegen
- 基线：`pod/e2-sema`（S3-04sema 后）

## 一、GC 根来源清单

| # | 根来源 | 规范 | 当前 codegen 登记 | 缺口 | owner |
|---|---|---|---|---|---|
| 1 | 栈局部变量 | S3 §8 | 无 `rt_gc_root_add/remove`；无栈槽位图 | 局部对象在 `new` 后未登记；无安全点/栈 map | E4 + E5 |
| 2 | 函数参数 | S3 §8 | 无根登记 | 参数对象（含协议/容器）未被根保护 | E4 |
| 3 | 顶层字段/全局 | S3 §8 | 无根登记 | 初始化后未 `rt_gc_root_add`，退出前收集可能误收 | E4 |
| 4 | singleton.instance | S2 §9.3 / S3 §8 | `singleton.go` 无根登记 | 实例未作为全局根登记 | E4/E5 |
| 5 | 数据枚举项 | S2 §8.3/S3 §3 | 无显式根 | 项对象常驻依赖「退出才收集」，无中途根 | E4/E5 |
| 6 | 闭包 env | S3 §8 | codegen 闭包发射部分，无 env external root | 闭包捕获对象未登记 | E4 |
| 7 | 任务 env | S3 §11 | `xrt_task_root_bind/unbind` API 存在但 codegen 不调用 | 任务存活期 env 不可达 | E4/E5 |
| 8 | ARC → GC 链 | S3 §5/§8 | 运行时扫描 ARC 头部分有；codegen 根链无 | 根部 ARC 对象字段指向 GC 时需被扫描 | E5 |
| 9 | 容器/协议/Any 字段 | S3 §5 | 容器非 GC；协议字段扫描缺失（S3 盘点 P0-7） | 含引用容器/协议字段的扫描/根 | E5 |

## 二、最小复现

1. **栈局部未被根保护**
```x
class N { N? next; }
static Int main() {
    var i = 0
    while (i < 1000000) {
        N n = new N()
        i = i + 1
    }
    return 0
}
```
若循环中插入安全点/收集中途触发，`n` 未被根登记 → 可能被提前回收（当前实现仅退出收集，故暂不显形）。

2. **全局字段未登记**
```x
N g = new N()
static Int main() { rt_gc_collect(); return g == null ? 1 : 0 }
```
全局 `g` 未 `rt_gc_root_add` 时，中途收集会误收（需 E5 暴露收集中途调用）。

3. **singleton 未登记**
```x
singleton AppInfo { N n = new N(); }
```
`AppInfo.instance` 未作为根；中途收集可能回收其字段。

4. **任务 env 未登记**
任务体捕获 `N`，`xrt_task_root_bind` 未被 codegen 调用；任务存活期间 GC 不可见。

| 补口 | 说明 | 用例 |

## 四、结论

- sema 已能标识 GC 根相关类型（singleton/数据枚举/容器/String 族）与容器环。
- codegen 当前**零根登记发射**，GC 仅在退出收集，故根缺口暂不显形；S3-02 必须由 E4/E5 补：
  1. E4：局部/参数/全局/singleton/闭包 env/任务 env 的 `rt_gc_root_add/remove` 与安全点发射；
  2. E5：安全点/栈 map/中途收集/ARC→GC 扫描；
  3. QA1：在上述最小复现上做中途收集压力用例。
- 本审计不修改 runtime/codegen；sema 只提供可见性用例和策略输入。
