## 四、审计结论

1. **可快速转 PASS（代码已具备，缺独立用例）**：FIELD-01（已 PASS）、INH-01（已 PASS）、BND-09、部分 BND-02/04/05/06 的声明面。
2. **sema 主场优先补**：BND-01（protected/public）、BND-02（abstract new/继承复用）、BND-05（§4.3 实现检查）、BND-06（switch 穷尽性）、BND-09（继承链基名）、BND-14（S2 负例矩阵）。
3. **跨线前置**：BND-03/DISP-01（vtable/派发）与 BND-07/08/13（singleton/factory/extension）依赖 E4 语法与 codegen；BND-10/MEM-01/02/BND-11 依赖 E5；E2 不单独承诺。
4. **建议实现顺序（审计后派卡）**：
   - 第 1 波（E2，sema 单域）：BND-05 → BND-06 → BND-02 → BND-01 → BND-09。
   - 第 2 波（E2+E4）：PCTOR-01 → PROTO-01 → ENUM-01 → STRUCT-01。
   - 第 3 波（E4/E3/E5）：DISP-01/BND-03 → BND-07/08/13/SINGLE/EXT → MEM/BND-10/11 → INT/BND-15 → GATE-01。
5. 本审计只读，未改 `impl/**`、未派实现卡；待董事会/owner 确认后按波次派卡。
