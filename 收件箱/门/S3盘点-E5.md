## 三、P0 缺口（S3 定版阻断）

### P0-1 ⚠ GC 清扫顺序：S3 §15 与 S2 §6.4 冲突
- S3 §15：「先 release 其 ARC 引用，再调用 deinit」；S2 §6.4：「deinit 执行时字段仍然有效，链路完成后释放」。
- 实现按 S2（`rt_gc.c`：deinit → scan 释放 ARC），`test_gc.c` 第 6 段断言 deinit 内 refcount==2。
- 影响：MEM-08；若按 S3 现状验收会判红。
- 处置：定版时修订 S3 §15（建议服从 S2），或回退 S2 条款；**必须先裁决，不能两版并存**。

### P0-2 ✗ 容器不是 GC 对象（S3 §10 明文）
- S3：`T[]`/`List`/`Map`/`Set` 是「分配头 + 长度 + 元素区」的 GC 对象；实现是 codegen 私有的值结构（`xn_arr_* {len,cap,data}`），作用域 `_free`，无头/无根/不可回收。
- 最小复现：
  ```x
  class Holder { List<Int> xs; }
  static Int main() { Holder h = new Holder(); return 0 }
  ```
  当前报 `容器字段 %s 的赋值需要引用语义容器（B2 范围，显式拒绝）`。
- 影响：§5 容器传播、§10 全部、MEM-06；容器跨函数/字段持有无法表达。

### P0-3 ⚠ String/Text/Bytes 策略与 §10/§188 冲突
- S3：String/Text/Bytes/StringBuilder 均 GC 对象；实现：`rt_string` ARC（`rt_string_new` 用 `RT_KIND_ARC`）、`xrt_bytes_buf` ARC（`runtime-contract.md` A0 已记录偏差）、Text/SB 未实现。
- 影响：§1 模型、§5 传播、§8 根；与 MEM-03/MEM-06 验收口径相关。
- 处置：裁决「随规范改实现（GC 化）」或「修订 S3 承认 ARC」（后者需同步 §1/§10/§15）。

### P0-4 ✗ 根集合/安全点/中途收集不完整（§8/§12）
- 现状：生成程序只在退出 `rt_gc_collect()`；无栈槽位根、无任务根、无分配阈值/循环回边安全点；`xrt_safepoint` 只刷隔离区。
- 最小复现：长循环内持续 `new` 环类对象——中途不收集，峰值内存单调增长；若手工插入收集，活跃局部未被根保护会被提前回收。
- 影响：MEM-03/MEM-09；§8 根集合、§12 安全点。

### P0-5 ✗ 逃逸分析与栈分配（§6/MEM-05）
- 现状：`Strategy.Escape` 恒为 `"n/a"`；无 `alloca`/栈对象发射；`none` 类对象仍堆 ARC。
- 最小复现：`class V { Int x = 1; } static Int main(){ V v = new V(); return v.x }` —— 生成 `rt_arc_new`。
- 影响：§6 三条提升规则全部未实现；MEM-05。

### P0-6 ⚠ Result 表示与 §9 冲突
- S3 §9：当前实现以 GC 盒表示 Result；实现：`xn_Result_Int_String` 是内联值结构（`codegen.go`），盒身份不暴露。
- 影响：§20「内联」优化已提前落地但未按 §25 验收声明；文档与实现需同步（建议 S3 新版改为「已内联」并补验收）。
- 最小复现：`xnull policy` + 生成 C 中 `xn_Result_Int_String` 为结构体、无 `rt_gc_new`。

### P0-7 ✗ 协议字段指向 GC 对象时未扫描/未正确释放（§5）
- 现状：`classField.isProto` 计入 `isRefField`，但 `scan` 只遍历 `isCls` 字段（`classes.go` scanFields）；GC 类 deinit 对协议字段走 `rt_release`（可能对 GC 目标计数释放）。
- 最小复现（概念）：GC 环类持有 `Shape s = <另一个 GC 类>` —— 对象不可达时扫描不到该引用；若目标为 GC，`rt_release` 语义错误。
- 影响：§5「协议字段使拥有者 GC」的传播只完成判定，运行面未完成。

### P0-8 ✗ 容器元素为 GC 类型被拒绝（§5/§10）
- 现状：`cType` 对 `List/Set/Map` 的 GC 类元素显式报错（`容器元素为 GC 类型 ... 暂未支持`）。
- 影响：§10「引用元素登记扫描区」无法满足；GC 环对象不能进容器。
