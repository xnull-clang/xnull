# B3-09 全量收口范围与验收（v1.0.0）

> 签发：董事会；状态：冻结。B3-09 开工即按本文件判定，不再扩缩范围。
> 依据：`handoff/B3-xnullc-plan.md` 第 156 行、`handoff/B3-09-baseline.md`、
> `handoff/B3-k06-clusters.md`、`handoff/B3-typedef-void-spec.md`。

## 1. 范围

- 输入集合：`git ls-files '*.x'`，排除 `evidence/`、`archive/`（历史证据/归档快照）。
- 当前基线：**241 个文件**；Go 可作入口 **143 个**（单文件 118、多文件 25）；
  负例/非入口 **98 个**。
- 入口判据：`xnull build --emit-c <entry>` 成功（多文件由 `--emit-ast-bundle`
  给出依赖后序闭包）；失败的按负例矩阵比对诊断/退出码，不参与 C diff。
- 大入口（AST/bundle 超过 argv 上限）必须走文件通道（K-07），不得以
  “无法传入”跳过；`impl/lib/b2/xparser.x` 是强制覆盖项。

## 2. 通过条件（全部满足）

1. **C 文本逐字节一致**：143 个 Go 入口的 `xnullc` 产物与 Go `--emit-c`
   `cmp` 为 0（不是归一化后 0）。逐文件记录 SHA-256。
2. **确定性**：同一入口连续生成两次，字节一致；分片重跑结果一致。
3. **负例矩阵**：98 个非入口的 Go 诊断码/退出码与 `xnullc` 一致（允许文本措辞
   差异，但诊断码、位置、退出码必须一致）。
4. **双路径**：9 个示例（`examples/*.x` 中可构建项）Go C 与 xnullc C 各自
   cc 编译运行，stdout/exit code 一致。
5. **构建脚本**：`tests/b3/run.sh` 不再串行跑完全部组；按包/用例切片并发，
   聚合门禁全 shard，任一 shard 红即整体红。
6. **全量测试绿**：`xnull build`/`go test` 基线全绿；B3 各组（01–09）全绿。

## 4. 门禁命令

```bash
# 全量：分片并发 + 聚合，任一 shard 红即整体红
bash tests/b3/xnullc-all.sh --all-shards 8 --parallel 8

# 单文件/多文件/负例明细
cat tests/b3/out/results.tsv

# 确定性
bash tests/b3/xnullc-all.sh --shard 1/8 --parallel 8   # 重跑比对
```

CI 与合并门禁必须跑完全部 shard，不允许只跑单分片。
