# S7 FFI 盘点（E5 运行时线）

- 日期：2026-11-08
- 性质：**只盘点**，不改代码、不改绑定、不动运行时
- 规范依据：`XNull解决方案-第7部分-FFI-v1.0.0.md`（§0—§11、附录 A/B）；
  S3 §18/§19/§22、S4 §7.3/附录 A、S5 §2.2/§9
- 基线：main `44d7681`（S6 收尾中；E5 工作树 `pod/e5-runtime` 同点）
- 现状证据：`go test ./internal/codegen/ffi` 全绿（13.1s，2026-11-08）；
  `go test ./internal/codegen -run 'TestS6_0[234]'` 全绿；`sh impl/runtime/build_rt.sh` 全套 exit 0

## 一、结论（先看这段）

1. **FFI 底座已过半**：`.xfb` 声明/合同校验、包装生成、句柄/租约、错误码映射、
   trampoline 生成、稳定 ABI 薄封装、阻塞分类清单都有可运行实现与测试。
2. **主要缺口不在“能不能写绑定”，而在“codegen 调用点是否消费”**：
   `ffi_gen.go` 的 P-09 注入只覆盖 `void/Int/Int32/Int64/Bool/String/handle/Bytes`，
   且错误码非零直接 `exit(134)`，没有映射为本地 `Result`。
3. **trampoline 与 `@unsafe` 是“生成器完成、集成未落”**：`EmitTrampoline` 没有调用方，
   `.xfb` 无法声明回调；`@unsafe` 只校验文本/路径，未接 S8 `link.unsafe` 构建门禁。
4. **长阻塞伴生形态只有校验**：`@longRunning` + `submit<Entry>` 的注册表校验在，
   但 codegen 未把 `.unaware + longRunning` 路由到 `xrt_companion_submit/wait`。
5. **按 S7 验收矩阵现状**：FFI-01/FFI-03 可维持 PASS；FFI-02/04/05/06/07 仍“部分”。
   台账（`XNull一致性用例台账-v1.0.0.md:103-109`）与此一致。

## 四、卡拆分建议

> 原则：先补“调用点消费”，再补“trampoline/@unsafe/ABI 转正”，最后收口矩阵。
> 每卡可独立验收，避免把 FFI 全部压成一张大卡。

| 卡 | 内容 | owner | 依赖 | 验收锚点 |
| --- | --- | --- | --- | --- |
| **S7-01 调用点编组扩展** | `ffi_gen.go` 支持 `Text`/`layout(c)`/数组/`Float`/`Char`/`UInt`；`.transfer` 句柄 `out` 形态；`Bytes` transfer/reclaim；`layout` 尺寸检查调用 | E4+E5 | FFI 底座（已完成） | FFI-02/FFI-03 |
| **S7-02 错误码 → Result** | 删除调用点 `exit(134)`；已知码 → `ErrorKind`，未知 → `Internal`，`Cancelled/Timeout` 不降级；同步 FFI 返回 `Result`；fileRead 等 XDK 入口改造 | E4+E5 | S7-01（可并行） | FFI-01/FFI-05、BOUND-02/03 |
| **S7-03 trampoline 集成** | `.xfb` 回调声明形态（或 codegen 内建）；`EmitTrampoline` 调用点；env 根生命周期；注销后调用/回调 panic 端到端 | E4+E5 | 运行时 `xrt_callback_env_*`（已完成） | FFI-05 |
| **S7-04 `@unsafe` 门禁** | 解析 S8 `link.unsafe`；未开启时构建失败；仅 `bindings/`；应用代码不可创建；合同文本必填 | E6+E4 | S8 清单解析 | FFI-04 |
| **S7-05 ABI v1 转正** | `xrt.h` 从候选冻结转稳定 v1；`xrt_runtime_init` 调用顺序；弱表 bindings-only 构建检查；原生链接测试 | E5+E6 | numeric 变体端到端 | FFI-06 |

### 建议顺序

1. S7-01 + S7-02（同一调用点改造，先让真实 XDK 同步入口不再 fatal）；
2. S7-03（trampoline 端到端）；
3. S7-04 + S7-05（门禁与 ABI 转正）；
4. S7-06（长阻塞路由）；
5. S7-07（QA 收口）。

## 五、边界与不做

- 本卡**只盘点**：不改 `.xfb`、不改 codegen、不改运行时。
- 不重定义 XDK API 名称与归属（S6 定稿）；S7 只规定跨语言合同。
- 不要求引入 sqlite 等第三方库；可用确定性自建原生库做端到端（现有 `ffi/emit_test.go` 已采用）。
- 解释器 `--interp` 无 FFI 桥；S7 只承诺编译路径，解释路径不属本部分验收。
- pin 的实现允许“不移动/临时搬迁计数”（S7 §11）；当前“拷贝+canary”是合法实现选择，但需在文档明确其可见语义。
- 不把“生成器有代码”当“合同可用”：每张卡必须给出 codegen 调用点或原生链接证据。
