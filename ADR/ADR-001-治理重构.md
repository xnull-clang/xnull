# ADR-001：治理重构——五线制与单一事实源

- **状态**：Accepted（试行 72 小时，2026-11-07 起）
- **依据**：专家评审 `收件箱/专家评审/评审意见-2026-11-07-v1.0.0.md`、`管理咨询备忘-组织与流程-2026-11-07-v1.0.0.md`（EXP-022–027）
- **用户授权**：2026-11-07「按专家方案试行，旧流程全部移除」

## 背景

两天内 13+ 份判决、655 个收件箱文件、32 个岗位、至少 4 套互相矛盾的看板（6/14 vs 7/14）；同期 M1 计数几乎未动。治理产出超过工程产出，单点批处理仲裁导致阻塞排队。

## 决定

1. **五线制**，取代 32 岗与 CEO1/2/3 管理层：

| 线 | Owner | 范围 |
|---|---|---|
| 前端线 | **E2** | xfront + sema；M1 收口、GEN/ERR/PKG/TUPLE |
| 自举线 | **E4** | codegen + B0–B4；B1 xnfmt、B2/B3/B4 |
| 运行时线 | **E5** | runtime / GC / ABI / FFI；CTO2 技术会签 |
| QA 线 | **QA1** | 独立验收、黄金用例、双路径/变异 |
| 发布线 | **COO** | 公开仓、发布物料；不碰代码 |

工具链/CI/IDE 归自举线，E6 执行；CTO1/CTO2 只做技术会签，不管理。

2. **董事会缩为门禁委员会**：只做门判定、owner 冲突仲裁、ADR 归档；**不派工、不看板、不写快照**。
3. **ADR 制**：决策一页（背景/决定/后果），签发即冻结；禁止同主题连环升版。旧判决全部归档。
4. **SSOT 看板**：唯一看板由脚本从 `git log + go test + 台账 status.tsv + evidence` 生成，手改即作废。停止所有手工看板、每小时快照、120s 刷新器。
5. **WIP**：每 owner 同时最多 2 张卡（1 开发 + 1 待验收）；全线在途 ≤10。
6. **SLA**：P0（门禁/停工）≤2h；P1 当日；P2 周批。只有死命令、预算、公开发布三类需用户裁决。
7. **汇报只报四个数**：本周 commit 数、锚点翻转数、全量测试绿/红、门进度。禁止以文件数/回执数/看板数为产出。
8. **回执只用于门证据**：普通任务不再每卡写回执；门禁仍按死命令四件套。
9. **预算修正**（EXP-016）：B1 8h、B2 48h、B3 72h；B4 拆 B4a 不动点 / B4b CLI+devtool / B4c 去 Go 构建，各 24h。
10. **B1 前置**：B1-00 格式规范已落；xnfmt 仅用文本 API 子集，B0-07c `fileClose` 不阻塞 B1，但列入 B2 前必清。

## 后果

- CEO1/2/3 会话与 32 岗任务表撤销（归档，不删除）；只保留五线 owner + 执行会话。
- 旧判决、看板、台账、快照、监控脚本移入 `收件箱/_归档/旧流程/`；全部停止使用。
- 专家 EXP-001–027 由各线 owner 起草处置，董事会只终审；blocker（001/002/017）当日回。
- 试行 72h 后复盘：若工程产出未升、治理文档未降，回滚本 ADR。
