# ADR-007 S3 定版裁决

> 日期：2026-11-08 01:45
> 状态：生效
> 依据：`收件箱/门/S3盘点-E5.md`；用户 01:40 四项裁决；`死命令.md` 第 1 号

## 背景

S3 盘点（E5，14.7KB）列出 8 个 P0、10 个 P1；其中四处为规范与实现的语义冲突，必须在 S3 定版前裁决。用户已逐项裁决。

## 决定

1. **GC 清扫顺序以 S2 §6.4 为准**：先执行 `deinit`，链完成后释放 ARC 引用；S3 §15 文本修订，不两版并存。
2. **容器与 String/Text/Bytes/StringBuilder 按 S3 §10 GC 化**：容器加分配头/根/扫描区，支持 GC 元素；不采用「修订规范承认 ARC/值结构」的降级路线。
3. **Result 修订 S3 §9 为「已内联值结构」**：保留现有内联实现，补 §25 验收声明；不回退 GC 盒。
4. **逃逸分析与栈分配（MEM-05）列入 S3/B2 前置**：必须实现，不得降为 §20 后置优化。

## 执行

- S3 母本 `XNull解决方案-第3部分-内存管理-v3.0.0.md` 冻结不改；修订以 `S3-v3.1.0-修订说明` 新文件发布，经 QA 一致性验收后定版。
- 卡序：S3-01 容器 GC 化 → S3-04 String/Text/Bytes/SB → S3-02 根与安全点 → S3-03 逃逸与栈 → S3-05 协议/Any/元组 → S3-07/08（已完成）→ S3-09（已完成）。
- S3-06（弱表/屏障并发化）随 B3 调度器，不阻塞 S3 定版。

## 后果

- S3 定版工作量按「全 GC 化」口径估算，工作量大于降级路线。
- 现有 ARC/String/Bytes 行为可保留为过渡，但对外语义按 GC 口径验收。
- 不设时钟；S3 验收全绿才进 B2 四件套。
