## 背景

1. `死命令.md` 原件在仓库与工作树中缺失（从未被 git 跟踪）；用户裁决：**按现有记录继续**。

## 决定

1. **B2 定义（沿用 v1.9.0）**：XNull 重写 lexer + parser → AST；全仓库 `.x` 的 AST 与 Go 版逐字节一致；解释器/编译器改用新前端。预算 24h。
2. **B2 硬前置**：
   - S1–S8 定版 + SHA-256 清单（`收件箱/门/S1-S8定版清单-v1.0.0.md`）；
   - 全量一致性验收绿（19 包 ok，2026-11-08 08:28 已确认）；
   - **XDK-09 net 补齐并 PASS**（本 ADR 新增）；
   - MEM-09/S3-06 的 B3 回验不作为 B2 前置，但 B3 门必须回验。
3. **B2 门禁**：上一门未过不得开工；不得用 Go 补功能再宣称达标；AST 逐字节一致才算 PASS。
4. **B3/B4 定义**（记录，不改变）：B3 XNull 写完整 `xnullc`（AST→C），Go 版 oracle 差分；B4 不动点 xn-s1→xn-s2→xn-s3，删 Go 后全量测试绿。

## 执行

- 自举口径在 B2 门通过前仍不得对外使用「已自举」。
