# ADR-003：断链恢复协议（接力棒 + 最后绿点）

- **状态**：Accepted（2026-11-07 14:20，ADR-001/002 试行期内生效）
- **问题**：加执行位后，owner → 执行位 → owner 的交接可能断；不能靠聊天记忆重建

## 决定

1. **每张卡一根接力棒**：`handoff/<卡片ID>.md`，七字段：
   `卡片ID / 输入 / 输出文件 / commit / 验证命令 / 已知缺口 / 下一步`
2. **没有接力棒 = 卡无效**：执行位开工前必须读上一棒；收工必须写下一棒。
3. **每条线一个最后绿点**：SSOT 看板记录 `last-green` SHA（该线最近一次全量测试绿的 commit）。
4. **断链检测**（任一触发即冻结该线）：
   - 2 小时无 commit；
   - 接力棒缺字段；
   - owner 集成测试红；
   - 执行位产出与接口合同不符。
5. **恢复四步**：
   ```
   冻结该线 → 回到 last-green → 按接力棒回放 → 重跑集成/接口测试 → 解冻
   ```
   禁止用聊天记录重建；只认接力棒 + commit。
6. **owner 是唯一集成人**；owner 不可用时由 CTO1/CTO2 按接力棒代集成，不得由执行位互相直连。
7. **回放失败两次**：该卡作废，owner 重新拆卡；执行位换人或降级。

## 理由

断链不可避免，但**工作不该丢**：commit 是检查点，接力棒是上下文，last-green 是回滚点。三者齐，链就能接上；缺一，只能靠人脑猜。
